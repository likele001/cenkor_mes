【升级影响 · 本次为新增功能，已有单据数据与计算口径一律不变，升级前请知悉】本次相对 v2.2.16 新增库存盘点单、不良品处置单、统一检验单（IQC / IPQC / OQC / FAI）与检验台账、返工单及四类基础台账（物料替代 / 工程变更 ECN / 设备停机 / 供应商评分），并把整批报工终审与检验依据打通。对照「旧数据和旧集成在不做任何操作的情况下会不会得到不同结果」这条判据，结论是：不会。以下按「哪类会变 / 哪类不变 / 历史数据怎么办 / 需要你做什么」逐项说明，便于快速判断自己是否受影响。

【哪类会变】无。本次不含任何改写存量单据、既有金额口径或既有必填入参的变更，没有需要逐单核对的历史数据。

【哪类不变 · 可据此直接排除自查】① 已有单据金额与计算口径不变：报价单税额（按行税率合计、tax_rate 仅为兜底税率）、工资、库存结存、盘点入账等既有算法一行未改；② 已有单据数据不重算、不回填：本次 4 个迁移（0016~0019）只做加法，新增 5 张台账表初始为空、inspection_orders 新增两列可空，升级过程不 UPDATE 任何存量行；③ 已有接口调用方式不变：POST /admin/production/reports/{id}/qc-approve 不传 inspection_id 时，审核流水、工资明细、追溯码、通知与状态流转与 v2.2.16 逐字一致，响应体只多一个可忽略的 inspection_code 键；④ 业务主档不动：新台账只登记，不自动改 BOM、设备 / 供应商主档、库存、reports.good_qty，也不推进采购 / 发货 / 工单 / 报工状态；⑤ 检验闸门仍不强制：是否必须挂检验单由客户按数据决定，系统不代业务拍板。

【历史数据如何处理】不自动重算、不自动回填。若需要把历史单据纳入新台账，按各自端点逐单操作。例：历史处置单补返工单用 POST /admin/production/dispositions/{id}/generate-reworks，该端点幂等，重复调用不会生成重复工单；一条「退回工序」明细始终只对应一张返工单。

【升级后需要你做的一件事】本次新增 11 个权限点（rework / substitute / ecn / downtime / supplier_score 的 view 与 manage 等）。内置角色由启动逻辑自动补齐，但客户自建角色不会自动获得这些权限——新菜单可能出现「看得见、点不动」。请在后台「角色管理」按岗位逐个授权：PUT /api/admin/system/roles/{id}/permissions，注意该接口是全量替换，须先读出该角色全量权限再合并回写，直接提交会清空原有权限。

【条件性提示 · 仅针对跑过中间代码的实例】若你的实例曾通过直接部署或「快路」更新跑过 0017 / 0018 之后、但未打 tag 的代码，本次起「批准处置单」会额外生成返工单，升级前已批准的处置单不会自动补，请用上面的幂等端点逐单补齐；同时 /admin/production/inspections/source-options 的 OQC / FAI 分支返回键与 label 文案相对中间版本有扩展，若有自定义前端依赖该返回体请核对。从 v2.2.16 正式升级的客户不涉及这两条，可直接跳过。

库存盘点单（0016_stocktake）：新增 stocktakes / stocktake_items，确认入账按「实盘 − 确认时账面」计算而非制单快照，期间收发不会被抹掉，未盘行不动；仓储侧新增盘点点选型号的下拉端点，避开仓管常无 sku.manage 的权限黑洞。

统一检验单与检验台账（0018_inspection）：新增 IQC / IPQC / OQC / FAI 四类检验单、模板快照、判定与关闭状态机（用 closed_at 保留 passed / failed 结论，不覆盖判定结果），检验记录台账可按条件查询、查看明细与导出；静态路由统一注册在 /{id} 之前，避免被解析成 id 返回 422。

质量主线联动与基础台账（0019_basics）：整批报工终审新增可选 inspection_id，传了才校验「IPQC + 判定合格 + 挂在本报工上」并把检验单号写入审核流水 reason；OQC 从发货单带出客户 / 产品 / 数量、FAI 从任务带出工序 / 产品 / 计划数，新增来源汇总与按报工查询端点；处置批准按「一条退回工序明细一张返工单」幂等生成，并完成开工 / 完成 / 作废状态机与良品数回流；新增物料替代、工程变更 ECN、设备停机、供应商评分四类台账，供应商评分总分按质量 40% / 交期 30% / 价格 20% / 服务 10% 由系统计算、停机时长只由起止时间算，均不接收前端传值。同步新增 11 个权限点、RW / ECN / DT 三种单号规则、返工单与基础台账两个管理页面及中 / 英 / 韩三语文案。
