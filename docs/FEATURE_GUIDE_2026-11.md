# 四项核心能力操作指南（2026-11）

> 适用版本：v2.3.1 之后（含迁移 0025 / 0026）
> 涉及：多级 BOM、送货单打印、按发货对账、H5 报工预估工资

## 一、多级 BOM

### 1. 概念

- BOM 明细行新增「半成品」开关：打开后，该物料对应**型号（SKU）**的 BOM 会被递归展开。
- 层级在运行时计算，不需要手工维护父子行；最大 10 层。
- 子级 BOM 只认 **SKU 级** 与 **产品级**，不会使用「全厂默认 BOM」兜底（避免所有物料被误判为半成品）。

### 2. 配置步骤

1. 先给半成品型号建好 BOM：`基础数据 → BOM`，范围选「SKU」。
2. 再建成品 BOM，在明细行把对应物料勾选「半成品」并填写单耗。
3. 保存时会校验：物料所属型号必须有 SKU/产品级 BOM；出现 A→B→A 会直接拒绝并提示「BOM 存在循环引用」。
4. 点列表里的「层级预览」，弹窗按层级展示展开结果与单件用量；缺失子 BOM 会提示数量。

### 3. 生效范围

- 工单齐套检查：半成品先按自身库存扣减，剩余量再展开到叶子物料，缺料数不再重复计算。
- MRP：只对叶子物料生成采购建议；半成品不进入采购行。
- 生产计划页的齐套/采购建议：同上。

## 二、送货单打印

### 1. 打印

`仓储 → 发货管理`，任一行点「打印送货单」，浏览器弹出打印窗口。
内容含：发货单号、订单号、客户、仓库、物流公司/单号、发货与签收时间、明细（编码/名称/规格/数量）、合计数量、备注、双方签字栏。

### 2. 导出 PDF

同一行点「PDF」，后端生成 PDF 并落附件库，返回 `/api/files/{id}?download=true`，浏览器新窗口打开后可下载。

### 3. 模板

- 首次打印会自动落库内置模板 `delivery_note`（送货单）。
- 需要改样式：`系统管理 → 打印模板` 编辑该模板；停用或删除后，下次打印会重新落内置版本。
- 自定义模板可用变量：`shipment.*`、`order.code`、`customer.*`、`warehouse.name`、`items_html`、`total_qty`、`printed_at`。

## 三、按发货对账

### 1. 新建对账单

`财务 → 客户对账单 → 新建对账单`：

1. 选客户；
2. 对账来源选「按订单」或「按发货」；
3. 按发货：勾选未对账、状态为已发货/已签收的发货单，下方实时显示合计金额；
4. 可填账期、到期日、备注；
5. 提交后生成草稿对账单。

### 2. 金额口径（重要）

- **按发货**：`发货数量 × 订单明细单价`。同一型号在订单里有多行时，取 `Σ小计 / Σ数量` 的加权单价。
- **按订单**：沿用原有口径 `默认工艺路线各工序工价之和 × 订单数量`。
- 两种口径不同，同一客户不要混用；文档与详情页均会标注来源。

### 3. 校验规则

- 发货单必须已发货（`shipped`）或已签收（`signed`）；
- 必须属于所选客户；
- 同一发货单/订单不能重复对账（详情页可看到来源与单号）；
- 发货明细的型号必须能在订单明细中找到，否则报错并指出发货单号。

## 四、H5 报工即时预估工资

### 1. 展示位置

- 批量报工：提交成功弹窗新增一行「预估工资：¥xx（单价 ¥x）」；
- 逐件报工：成功提示改为「提交成功，本件预估 ¥x」。

### 2. 计算口径

与终审生成工资条完全一致：`型号 + 工序` 的生效工价 × 合格数量。
未配置工价时显示「该工序未配置工价，暂无法预估工资」，不影响报工提交。

### 3. 注意

- 预估只是即时参考，最终金额仍以审批通过后的工资条为准；
- 工价调整后，新报工按新工价预估，历史工资条不回溯。

## 五、升级与回滚

- 新增迁移：`0025_bom_subassembly`、`0026_statement_shipment`，均为加列/放宽非空，可 `alembic downgrade -1` 逐级回退。
- 升级后需重启后端进程；管理端与 H5 需重新构建 dist。
- 建议升级前备份 `material_bom_items` 与 `statement_items` 两张表。
