lightmes（SaaS） × cenkormes（独立版）功能对比清单

版本定位核查 开源决策参考 2026-08-21

用于区分「商业收费的 SaaS 版」与「计划开源（AGPL）的独立版」，明确开源独立版应包含什么、收费项留在哪里。

核查对象：lightmes/backend（SaaS 主仓）　×　cenkormes/backend（独立版）
核查方式：服务端实际 Model / API 路由注册比对（非关键词表象）
API 规模（@router 计数，非精确 endpoint）：lightmes 748 条　vs　cenkormes 539 条
双方都有 开源独立版完整保留 SaaS 独有 建议留商业收费 / Pro 侧 半成品 独立版有表但未挂功能 API

一、版本定位

版本定位许可 / 商业模式分包说明
lightmes SaaS 版（全集，含多租户平台层） 商业收费 community/（AGPL 公开）+ pro/（私有 overlay）——两个分包都属于 SaaS 侧
cenkormes 独立版（单租户私有部署版） 计划开源（AGPL-3.0） 独立仓库，不含 SaaS 平台层

三、SaaS 独有 / 独立版差异项（开源决策重点）

仅 lightmes（SaaS）有

功能层级
AI 员工（ai_employee）SaaS 独有
行业模板（industry）SaaS 独有
报价（quotation）SaaS 独有
模具管理（mold API）SaaS 独有
SPC 统计过程控制（spc API）SaaS 独有
SaaS 平台层（api/platform：租户/套餐/订阅）SaaS 独有
平台用户 / 套餐 / 订阅订单表SaaS 独有

建议：这些留在 SaaS / Pro 侧，作为商业收费差异化项，不入开源独立版。

仅 cenkormes（独立版）有 / 半成品

功能层级
追溯树（trace/tree/{product_code}）独立版亮点
CRM 适配器（crm-adapter）独立版亮点
注意：独立版 无任何独有 Model，上述独有均为 API/路由特色。
模具：只有 models/mold.py 表有表无功能
SPC：只有 models/spc.py 表有表无功能
报价：只有模型，无独立模块有表无功能

「有表无功能」= 模型文件在，但 /admin/* 未挂载对应路由，属未完成的半成品。

四、落地上建议

  • 开源独立版（cenkormes）直接开源即可：核心制造闭环完整，天然不含 AI 员工 / 行业模板 / 报价 / SPC / 模具功能 / SaaS 平台层，这些收费项本就在 SaaS 侧，无需「砍功能」。
  • 独立版推荐额外打磨的差异化亮点：trace/tree 追溯树、crm-adapter、exec_dashboard 执行看板——这些作为开源版的特色，利于推广。
  • 若决定做「批次级溯源」，再考虑补 incoming_batch（来料批次）；当前它只是采购验收时写入的一条批次记录，无独立页面、未接入 trace，是否补齐取决于产品规划。
  • 独立版的「有表无功能」（mold / spc / quotation）要么补全挂路由，要么在文档中标注「未开放」，避免使用者误以为功能缺失是 Bug。
