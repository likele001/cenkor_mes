# Release Notes

> 说明取自 `backend/CHANGELOG.json`（版本号真源为根目录 `VERSION`）。本文件用于留档，
> 便于在 GitHub Actions 因账单锁定无法自动建 Release 时，手动到
> https://github.com/likele001/cenkor_mes/releases/new 复制粘贴对应描述。

## v2.1.0 — 2026-10-06
新增库存归属维度、工资发放状态与审批记录、MRP 落地及库存数量非负约束；新增员工自助服务模块并优化权限控制；重构 WebSocket 实时推送与数据库迁移链；移除废弃薪资 API 定义

## v2.0.7 — 2026-10-05
新增对账单/库存 Excel 导出、消息中心管理界面、飞书推送管理（配置/绑定/群组/日志/测试/诊断/卡片预览）；修复群与个人推送规则及群组地址识别；优化租户设置 CRUD；修复自动化设置接口 /plans 页 404

## v2.0.6 — 2026-10-04
财务域清理与新功能：删除 erp_* 孤儿模块(含 drop 迁移 0006)；AR/AP 客户/供应商对账单新增账龄分析与部分核销(逐笔登记/冲销、到期日、账龄看板，全栈+i18n)

## v2.0.5 — 2026-10-04
新增核心闭环HTTP集成测试、CI质量门禁与请求可观测性(访问日志/慢查询/X-Request-ID)
