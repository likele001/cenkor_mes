### CenkorMES
- 定义：本项目对外名称（仓库根 README 与 VERSION 文件中使用），是一套面向中小型加工厂的轻量化 MES（制造执行系统），采用 AGPL-3.0 开源协议，支持单租户私有部署，覆盖产品/型号 → 工序/工价 → 客户/订单 → 工单 → 任务派驻 → 扫码报工 → 审核 → 自动算薪的全流程追溯。
- 别名：辰科MES、cenkormes

### MES
- 定义：制造执行系统（Manufacturing Execution System），在本项目中指代围绕工厂车间的生产计划、工单派发、报工质检、设备对接与自动算薪等业务闭环。

### 小程序
- 定义：指 `lightmes-miniapp/` 目录下的微信小程序端，基于 uni-app 框架开发，包含 pages-admin（管理）、pages-employee（员工）、pages-customer（客户）三套页面集合，通过 `dev:mp-weixin` / `build:mp-weixin` 脚本构建。
- 别名：微信小程序、miniapp、lightmes-miniapp

### H5
- 定义：指 `frontend-h5/` 目录下的移动端 Web 应用（非小程序），面向员工与客户端，技术栈为 Vue 3 + Vant 4 + Pinia，独立于 PC 管理后台与小程序。
- 别名：前端 H5、h5

### admin-pro
- 定义：指 `frontend-admin-pro/` 目录下的 PC 管理后台前端，技术栈为 Vue 3 + Element Plus + Pinia + ECharts + Tailwind CSS，标题为「辰科MES 管理后台」，是管理员进行全量业务配置的入口。
- 别名：PC 管理后台、管理后台、frontend-admin-pro

### 铺布机
- 定义：项目中涉及的工业硬件设备类型之一，代表需要通过设备对接模块与 MES 系统联动的车间生产设备（如铺布机等），由 `backend/app/api/admin/equipment` 及设备相关模型承载。
- 别名：设备
