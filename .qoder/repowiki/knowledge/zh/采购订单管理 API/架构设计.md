模块以 FastAPI `APIRouter` 为入口：`router.py` 仅负责挂载子路由（prefix=`/orders`, tags=`admin-purchase-orders`），业务逻辑集中在 `orders.py`。
- 依赖方向：本模块只向上依赖 `app.api.admin.system.common.write_op_log`、`app.core.*`（权限/DB/用户）、`app.crud.purchase_order`、`app.crud.material/supplier/warehouse`、`app.schemas.purchase_order`、`app.tasks._sync_excel`；不直接访问 ORM 模型，CRUD 与状态机封装在 `app.crud.purchase_order` 中。
- 权限边界：所有路由通过 `Depends(require_permissions(["purchase.manage"]))` 统一鉴权。
- 数据流：请求 → 校验供应商/物料/仓库有效性 → 调用 CRUD 层执行业务 → `db.commit()` → 重新查询带 items 的 PO → 返回 `ok(_out(...))` 序列化结果。
- 关联数据库模型：`PurchaseOrder` / `PurchaseOrderItem`（由 `app.models.purchase_order` 定义，经 `app.crud.purchase_order` 暴露），并通过外键关联 `Supplier`、`Material`、`Warehouse`。
