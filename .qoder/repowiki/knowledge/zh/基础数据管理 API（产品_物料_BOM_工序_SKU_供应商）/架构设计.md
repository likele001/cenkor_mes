模块以 FastAPI `APIRouter` 为最小单元组织：每个主实体一个文件（products.py / materials.py / boms.py / processes.py / process_routes.py / process_prices.py / skus.py / suppliers.py），由 router.py 统一聚合并挂载到 `/admin/master/{entity}` 路径下，通过 `include_router(prefix=..., tags=[...])` 注册。

- 依赖方向：router → app.crud.*（持久化）→ app.models.*（SQLAlchemy ORM）；校验走 app.schemas.*；业务辅助（编码生成、显示名、SKU 范围判断等）位于 app.services.*；Excel 导出复用 app.tasks._sync_excel.make_excel_response。
- 权限控制：每个子 router 在构造时注入 `dependencies=[Depends(require_permissions(["xxx.manage"]))]`，按资源维度隔离权限。
- BOM 是跨实体的核心聚合：boms.py 同时消费 product/sku/material CRUD，并通过 `get_effective_bom_for_sku` 实现 SKU→Product→Global 三级作用域解析，还提供 `/resolve/{sku_id}` 与 `/copy-to-sku` 两个扩展端点。
- 数据库变更防护：boms.py 对 OperationalError/ProgrammingError 做捕获，若错误文本包含 scope/product_id/is_default 等字段则返回 400 提示执行 alembic upgrade head（含 0033_bom_scope）。
