模块按业务域在 `pages-customer/` 下以路由目录组织：`notification/`（消息列表与订阅）、`order/`（详情、进度、发货、售后）、`statements/detail/`（账单详情）。每个子页均为独立的 Vue 3 `<script setup lang="ts">` 单文件组件，通过 uni-app 的 `onLoad/onShow` 生命周期从 URL query 中读取 `id` 参数并调用 `@/api/h5/customer` 或 `@/api/h5/notifications` 发起后端请求；跨页面跳转统一使用 `uni.navigateTo`。

- 共享 UI 能力下沉到 `components/customer-ui/CustTabBar.vue`，作为底部导航栏，通过 `active` prop + `uni.reLaunch` 切换 `/pages/customer/tab-{0,1,2}/index` 三个主入口。
- 样式统一通过 `@use '@/styles/customer-theme.scss'` 引入主题变量，所有页面复用 `cust-page/cust-card/cust-tag/cust-btn-*` 等原子类。
- 依赖方向单向向外：页面 → composables（`useCustomerLabels`、`useCustomerLocale`、`usePermission`）→ API 层 → 后端 FastAPI 端点（如 `/miniapp/wechat-mp/my-subscriptions`），不互相引用页面代码。
