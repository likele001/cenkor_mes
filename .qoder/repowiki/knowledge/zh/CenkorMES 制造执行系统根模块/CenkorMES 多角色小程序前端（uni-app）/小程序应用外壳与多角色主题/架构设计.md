模块由三部分组成，职责清晰且相互独立：
- `custom-tab-bar/`：微信小程序原生 `Component`，通过 `EMPLOYEE_TABS` / `ADMIN_TABS` 两套路由表按 `wx.getStorageSync('cenkormes_app_mode')` 动态切换菜单；对外暴露 `refreshList`、`setSelectedByPath`、`setBadge` 三个方法供页面调用。
- `mixins/tabBar.ts`：TypeScript 工具函数，通过 `getCurrentPages()` + `page.getTabBar()` 反射调用自定义 TabBar 的 API，实现 `syncTabBarSelected`（同步选中态）和 `updateTabBarBadge`（设置第4个 tab 徽标）两个横切能力。
- `styles/{admin,customer,employee}-theme.scss`：三份 SCSS 主题文件，各自定义一套以角色前缀命名的 CSS 类（`.adm-*` / `.cust-*` / `.emp-*`），统一从 `uni.scss` 引入设计令牌（$brand/$slate/$space/$radius/$shadow 等），分别对应管理端蓝紫系、客户端青色系、员工端蓝色工厂风。
依赖方向单向：mixin 反向调用 custom-tab-bar 暴露的方法；主题 SCSS 仅消费 uni.scss 的设计令牌，不引用 JS 逻辑。
