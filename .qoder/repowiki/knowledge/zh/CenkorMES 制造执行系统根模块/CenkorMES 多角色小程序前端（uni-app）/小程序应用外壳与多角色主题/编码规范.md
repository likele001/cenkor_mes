- 每个角色主题 SCSS 文件以独立的品牌色变量族开头（如 `$adm-brand*`、`$cust-brand*`、`$brand`），并通过统一的类名前缀（adm-/cust-/emp-）区分不同角色的 UI 组件。
- 所有尺寸、间距、圆角、阴影、字号等视觉常量均从 `uni.scss` 引入，避免在主题文件中硬编码具体数值。
- 交互元素普遍采用 `transition: transform $dur-fast $ease-smooth` 配合 `&:active { transform: scale(0.98) }` 的按压反馈模式。
- 自定义 TabBar 通过 `setData` 暴露 `refreshList` / `setSelectedByPath` / `setBadge` 方法，外部页面通过 `getTabBar()` 反射调用而非直接耦合内部数据结构。
