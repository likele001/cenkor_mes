模块分为两层：
- `pages-admin/` 下按后端业务域（audit/crm/dashboard/equipment/finance/master/notification/plans/production/purchase/quality/reports/system/warehouse）划分目录，每个子目录对应一个或多个小程序页面；典型页面仅做薄壳，直接 `<AdminXxxPage />` 并可选调用 `requirePermission('xxx.manage')` 做权限校验。
- `components/admin-ui/` 提供可复用的管理端 UI 组件：通用 CRUD 容器 `AdminCrudPage.vue` + 列表骨架 `MListLayout.vue` + 键值网格 `AdminKvGrid.vue` + 表单弹窗 `AdminFormPopup.vue`，以及各业务域的专用页面组件（如 `AdminOrderPage`、`AdminUserPage`、`AdminPlanPage`、`AdminKanbanPage`、`AdminScreenPage` 等）。
- 导航入口通过 `constants/adminMenu` 中的 `useAdminMenu()` 暴露菜单分组，由 `AdminMenuSection.vue` 渲染成图标网格，页面侧通过 `uni.navigateTo` 跳转。
- 数据层依赖外部 composables（如 `useAdminCrudPage`、`usePermission`），本模块不直接访问 API，仅负责视图装配与交互编排。
- 依赖方向单向：pages → admin-ui 组件 → composables/constants，组件之间无循环依赖。
