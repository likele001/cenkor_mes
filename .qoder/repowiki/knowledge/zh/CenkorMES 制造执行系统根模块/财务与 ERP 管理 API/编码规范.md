- 路由函数统一通过 `Depends(get_db)` 和 `Depends(get_current_user)` 注入会话与用户，并以 `ok({...})` 返回标准响应体。
- 权限控制集中在 router 构造处，使用 `dependencies=[Depends(require_permissions([...]))]` 声明所需权限（如 `finance.manage`、`erp.manage`）。
- 业务单号生成统一调用 `resolve_code(db, biz_type=BizType.X, code=..., exists=..., duplicate_msg=...)`，避免手写去重逻辑。
- 实体序列化通过文件内 `_out` / `_entry_out` 辅助函数将 ORM 对象转为 dict，并对 Decimal 字段显式 `float()` 转换。
- 状态变更接口先查询实体再校验当前状态（如仅 draft 可修改/删除/过账，仅 confirmed 可标记已收款），非法状态抛 `HTTPException(400)`。
- 分页列表接口统一接受 `offset`/`limit` Query 参数，且 limit 限制在 1~200 之间。
