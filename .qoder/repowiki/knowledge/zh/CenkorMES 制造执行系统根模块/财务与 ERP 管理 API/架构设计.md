模块由两个并列的 FastAPI 子应用组成：
- `finance/`：客户对账单（`router.py`）+ 供应商对账单（`supplier_statements.py`），通过 `include_router` 挂载到同一 `finance.manage` 权限下；负责从订单聚合金额生成 Statement，确认时写入 `FinanceLedger` 应收/应付分录，并触发飞书通知。
- `erp/`：以 `router.py` 为聚合入口，按领域拆分为 `invoices`（发票）、`vouchers`（记账凭证）、`accounts`（会计科目）、`costs`（成本）、`assets`（固定资产）、`reports`（试算平衡/资产负债表）六个子 router，统一挂载在 `erp.manage` 权限下。
依赖方向单向向下：路由层 → `app.crud.*` / `app.schemas.*` / `app.models.*` / `app.services.code_generator`，不直接写 SQL（除利润统计使用 SQLAlchemy select）。所有写操作经 `db.commit()` 提交，状态机校验（draft→posted/void、draft→confirmed→paid）在路由层做前置守卫。
