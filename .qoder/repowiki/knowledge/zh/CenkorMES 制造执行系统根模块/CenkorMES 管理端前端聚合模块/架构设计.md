本模块是后端 FastAPI 的 Web 管理前端入口，将各业务子域的 Vue 页面通过集中式路由装配为单一应用：
- 路由与权限：`src/router/index.ts` 统一注册所有 `pages/<domain>/` 下的页面，URL 前缀（/system、/master、/production、/warehouse、/purchase、/finance、/erp、/dashboard、/reports）即业务域边界；`meta.permissions` 由全局 `beforeEach` 守卫经 `auth.hasAnyPermission` 校验，公共页面标记 `meta.public: true`。
- API 契约：`src/api/*.ts` 为每个后端模块提供 axios 封装，页面组件仅调用这些函数，不直接持有 HTTP 客户端；token 与用户信息来自 Pinia store（`stores/auth.ts`、`stores/app-config.ts`）。
- 共享层：`components/admin/*`（AdminPage/AdminDataTable/AdminFilterBar 等）与 `composables/useListPage.ts`、`useExport.ts`、`useTheme.ts`、`useSidebarCollapse.ts` 被所有子域页面复用，形成跨子模块的 UI 与横切逻辑基线。
- 国际化：菜单标题与文案统一走 `locales/zh-CN.ts`、`en-US.ts`、`ko-KR.ts`，路由 meta.title 通过 `i18n.global.t('menu.xxx')` 解析。
- 部署：Vite 产物经 `nginx-admin.example.conf` 反向代理到后端 FastAPI，开发态由 `start.sh` / `run.bat` 启动。
