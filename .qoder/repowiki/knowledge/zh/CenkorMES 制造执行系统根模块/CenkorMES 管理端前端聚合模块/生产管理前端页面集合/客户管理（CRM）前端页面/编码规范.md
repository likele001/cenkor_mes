- 所有用户可见文案通过 `t('production.customers.*')` 或 `t('production.common.*')` 取国际化键值，不在模板中硬编码中文。
- 异步请求统一采用 `loading.value = true; try { ... } finally { loading.value = false }` 模式包裹，确保异常时也能恢复加载态。
- 弹窗/抽屉使用 `reactive({ open, saving, form: {...} })` 集中声明状态，保存前校验必填字段并通过 `ElMessage.success/warning/error` 反馈结果。
- 列表页同时渲染桌面端 `el-table` 与移动端 `admin-mobile-row` 两套视图，通过 `hidden lg:block` 与 `lg:hidden` 切换显示。
- 权限敏感操作通过 `canManageCustomer` / `isAdmin` computed 计算后在模板中使用 `v-if` 控制按钮显隐，而非在方法内判断。
