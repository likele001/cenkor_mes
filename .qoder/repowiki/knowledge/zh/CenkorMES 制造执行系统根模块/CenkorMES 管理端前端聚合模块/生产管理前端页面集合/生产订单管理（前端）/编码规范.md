- 表单数据以 `reactive({...})` 声明，异步选项加载用 `optionsLoading` 标志包裹 try/finally，避免 loading 泄漏。
- 多语言文案统一通过 `useI18n().t('production.orders.*')` / `production.common.*` 键读取，不在模板中硬编码中文。
- 订单状态展示走 `useStatus('order')` 返回的 `label` / `type`，按钮禁用条件集中写在模板表达式中（如 `row.status !== 'draft' && row.status !== 'confirmed' && row.status !== 'producing'`）。
- SKU 行操作（新增/删除）遵循「至少保留一行」规则：`lines.length <= 1` 时禁用删除按钮，提交前过滤空行并校验至少有一行有效 sku_id 与 qty。
- 对外暴露的弹窗组件通过 `defineExpose({ resetForm })` 暴露重置方法，父组件在打开对话框前调用以初始化 form 状态。
- Excel 下载统一采用 `URL.createObjectURL(blob)` + 动态 `<a>` 触发下载，并在 finally 中 `URL.revokeObjectURL` 释放内存。
