- 页面统一以 `AdminPage` 作为外层容器，并通过具名插槽 `#actions` 放置搜索/导出/新建按钮，通过 `#extra` 承载编辑弹窗。
- 列表页采用统一的查询参数结构 `{ keyword, offset, limit, include_inactive }`，分页通过 `page = Math.floor(offset / limit) + 1` 与 `fakeTotal = offset + items.length + (items.length === limit ? limit : 0)` 计算。
- CRUD 操作遵循 openCreate/openEdit/onSave 三段式：openCreate 清空 id 并初始化表单，openEdit 拷贝行数据到 dlg.form，onSave 先 formRef.validate() 再按是否存在 id 调用 createXxx/updateXxx。
- 禁用/删除等危险操作统一使用 `el-popconfirm` 二次确认，并在 finally 中重置 loading/saving 状态。
- 多端展示通过 `hidden lg:block` 的 el-table 与 `lg:hidden` 下的 `admin-mobile-row` 卡片两套模板并列实现桌面/移动端适配。
- 所有用户可见文案通过 `t('system.<resource>.<key>')` 或 `$t('<resource>.<key>')` 从 i18n 读取，不在模板中硬编码字符串。
