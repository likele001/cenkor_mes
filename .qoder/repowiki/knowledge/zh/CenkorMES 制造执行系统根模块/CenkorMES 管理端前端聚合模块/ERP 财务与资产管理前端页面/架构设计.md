本模块为纯展示层（Vue SFC），每个 `.vue` 文件对应一个后端实体/报表，统一通过 `@/api/erp` 暴露的 `erpApi` 调用 FastAPI 后端接口，不直接访问数据库。
- 页面按业务域划分：账务（AccountsPage、VouchersPage）、资产生命周期（AssetsPage、AssetDepreciationPage、AssetCheckPage）、财务报表（BalanceSheetPage、TrialBalancePage）、票据与成本（InvoicesPage、WorkOrderCostsPage）。
- 所有页面复用 `@/components/admin/AdminPage.vue` 作为布局容器，使用 Element Plus 的 `el-table` / `el-dialog` / `el-form` 构建 CRUD 表单与表格。
- 数据交互遵循统一的 try/catch + ElMessage 错误提示模式；列表页在 `onMounted` 中调用 `reload(true)` 拉取数据，并通过 `erpApi.listXxx` / `createXxx` / `updateXxx` / `deleteXxx` 完成增删改查。
- 跨页面协作通过共享 API 类型（如 `AccountOut`、`FixedAssetOut`、`VoucherOut`）和下拉选项（如 VouchersPage 调用 `erpApi.accountOptions()` 获取科目列表）实现。
- 无独立路由或状态管理逻辑，路由注册由上层 router 配置负责；本目录仅承载页面视图与内联业务脚本。
