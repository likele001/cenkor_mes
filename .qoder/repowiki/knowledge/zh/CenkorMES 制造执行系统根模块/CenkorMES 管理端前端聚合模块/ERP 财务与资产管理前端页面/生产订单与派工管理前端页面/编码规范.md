- 分页统一使用 reactive query 对象（offset/limit）配合 computed page 与 fakeTotal，reload(reset) 在 finally 中关闭 loading。
- 状态标签通过 useStatus('order'|'work_order') 获取 label/type，任务状态则在本地用 taskStatusLabel/taskStatusType 函数映射 pending/working/done。
- 表格列与移动端卡片采用 desktop/mobile 双模板：桌面端用 el-table，移动端用 .admin-mobile-row + dl.admin-mobile-kv 布局。
- 对外部 API 调用包裹 try/finally 释放 loading/saving 标志，失败时由上层 http 拦截器提示，catch 块通常为空。
- 表单选项（客户/SKU/员工/技能/设备）在对话框 @opened 钩子中按需加载，并通过 optionsLoading 字段显示局部加载态。
- 导出 Excel/PDF 统一通过 URL.createObjectURL + 动态 a 标签触发下载，并在 finally 中 revokeObjectURL。
