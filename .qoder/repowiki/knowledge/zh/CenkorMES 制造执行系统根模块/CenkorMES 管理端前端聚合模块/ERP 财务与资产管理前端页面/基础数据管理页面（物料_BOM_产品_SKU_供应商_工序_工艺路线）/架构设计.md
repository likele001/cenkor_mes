该模块为扁平的页面级组件集合，每个 `*.Page.vue` 文件对应一个后端实体（Material / Product / Sku / Supplier / Process / ProcessRoute / Bom / ProcessPrice / SkuBatchWithPrices），统一通过 `AdminPage` 布局组件承载，并在 `#actions` 插槽中放置搜索、开关、导出与新增按钮。

- 数据获取：通过 `@/api/materials`、`@/api/master` 等 API 模块调用 FastAPI 后端的 CRUD 接口；部分页面使用 `useListPage` composable（如 ProductsPage）封装分页查询，部分页面（如 MaterialsPage）自行维护 `query.offset/limit/include_inactive`。
- 表单与弹窗：所有页面的新增/编辑逻辑集中在 `dlg` reactive 对象 + `el-dialog` + `el-form` + Element Plus `FormRules` 校验，新建时通过 `previewNextCode` 预取编码、提交时用 `codeForSubmit` 生成最终编码。
- 关联展示：对多端关联字段（如物料的 supplier_id）通过 `partyOptionLabel` 工具函数将 ID 映射为可读文本。
- 状态管理：实体启用/禁用通过 `is_active` 布尔字段控制，禁用操作经 `el-popconfirm` 二次确认后调用 `disableXxx` 接口。
- 导出：各页面实现统一的 `exportExcel` 模式——调用 API 返回 Blob，用 `URL.createObjectURL` 触发下载并清理 URL。
- 依赖方向：页面 → `@/components/admin/*`（UI 容器）、`@/composables/useListPage`（分页）、`@/api/*`（HTTP 客户端）、`@/utils/code` & `@/utils/display`（通用工具），不反向依赖业务服务层。
