本模块由三个独立的 Vue 单文件组件构成，均位于 `src/pages/production/` 下，作为生产质检子系统的用户入口：
- `InspectionTemplatesPage.vue`：质检模板（inspection-templates）CRUD，支持按工序/产品关联、检查项（合格/不合格、测量值、文本描述）动态增删，调用 `/admin/production/inspection-templates`。
- `DefectCodesPage.vue`：缺陷代码（defect-codes）CRUD，含严重程度（critical/major/minor）枚举映射与 Excel 导出（`/admin/production/quality/defect-codes/export`），调用 `/admin/production/defect-codes`。
- `TracePage.vue`：成品码溯源查询，通过 `/admin/trace` 列表 + `/admin/trace/{code}` 详情接口拉取 flow_chain、audits、salary、media、qr 等聚合数据，并借助 `@/api/production.productionApi.printProductLabels` 与 `@/utils/print.openPrintWindow` 实现标签打印。

依赖方向单向指向后端 REST API，不直接操作数据库；UI 统一基于 Element Plus 与项目内 `AdminPage` 布局组件，国际化通过 `vue-i18n` 的 `t('production.xxx')` 键加载。
