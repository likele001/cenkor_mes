- 页面统一以 `AdminPage` 包裹，并在 `#actions` 插槽中放置筛选器与“新建/刷新”按钮。
- 列表加载采用 `loading` ref + try/catch + finally 重置的模式，错误通过 `ElMessage.error(e?.message || t('erp.common.loadFailed'))` 提示。
- 金额字段在模板中以 `¥ {{ formatMoney(row.xxx) }}` 展示，`formatMoney` 使用 `toLocaleString('zh-CN', { minimumFractionDigits: 2, maximumFractionDigits: 2 })` 格式化。
- 删除与关键状态变更（如 post/unpost）先通过 `ElMessageBox.confirm` 二次确认，再调用 API 并刷新列表。
- 枚举型字段（subject_type、category、depreciation_method、direction 等）直接在模板中以 `el-option` 硬编码可选值，而非从后端字典接口获取。
- 表单提交前根据 `editingId` 判断走 `erpApi.updateXxx(id, payload)` 还是 `erpApi.createXxx(payload)`，成功后关闭弹窗并 `reload(true)`。
