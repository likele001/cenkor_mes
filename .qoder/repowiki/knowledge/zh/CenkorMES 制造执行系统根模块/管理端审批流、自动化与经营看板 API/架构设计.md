三个并列的子模块均遵循 FastAPI 单文件 router 模式，仅暴露 HTTP 接口，业务逻辑下沉到 `app.crud` 与 `app.services`：
- `approval/router.py`：基于 `biz_type` 的可编排审批流 CRUD，通过 `set_steps` 维护多级审批步骤（approver_role / step_order / can_skip），依赖权限点 `setting.manage`。
- `automation/router.py`：提供自动化规则设置（`AutomationSettingsIn`）、Dry-Run 预检查（`precheck_order_for_automation` / `precheck_plan_for_automation`）与执行日志分页查询，按资源粒度分别绑定 `setting.manage` 与 `plan.manage` 权限。
- `exec_dashboard/router.py`：Pro 专属老板看板，统一以 `period=today|week|month|quarter` 为时间维度，调用 `app.crud.exec_dashboard` 中的聚合函数输出销售额/毛利率/准交率/回款率/产能利用率五大指标及下钻数据，入口权限点 `exec_dashboard.view`。
依赖方向单向向外：router → app.crud / app.services → SQLAlchemy ORM；所有响应经 `app.core.response.ok` 包装，鉴权与 DB Session 通过 `app.core.deps` 注入。
