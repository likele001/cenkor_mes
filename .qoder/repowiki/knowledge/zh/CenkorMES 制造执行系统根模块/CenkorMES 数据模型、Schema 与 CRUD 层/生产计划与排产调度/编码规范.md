- CRUD 函数统一以 `db: Session` 作为首参，返回 ORM 对象或元组结果，使用 `db.flush()` 而非 `db.commit()` 将提交责任交给上层事务。
- 查询构造采用 `select(...).where(...)` 链式组合，分页通过 `.offset(offset).limit(limit)` 实现，可选过滤条件在构建语句后按需追加。
- 跨模块业务逻辑通过函数内 `from ... import ...` 延迟导入（如 `Task`、`WorkOrder`、`create_work_orders_for_order`），以避免生产计划与工单/任务之间的循环依赖。
- 状态变更类操作先校验 `plan.status == 'planned'`，不满足时抛出 `ValueError` 并附带面向用户的中文提示消息。
- Pydantic 入参模型对数值字段统一使用 `Field(ge=..., le=...)` 做范围约束，字符串字段用 `max_length`/`min_length` 限制长度。
