模块按 FastAPI 标准三层拆分：
- `models/production_plan.py`：基于 SQLAlchemy 2.0 的 ORM 模型 `ProductionPlan`，表 `production_plans`，通过 `UniqueConstraint('code')` 保证计划编码唯一，外键关联 `orders.id` 与 `users.id`，并维护 `released_at/released_by` 下发审计字段。
- `schemas/production_plan.py`：Pydantic v2 请求模型，覆盖计划创建(`ProductionPlanCreateIn`)、更新(`ProductionPlanUpdateIn`)、确认下发(`ProductionPlanReleaseIn`)，以及排产相关的产能数据(`CalendarDayUpsertIn`、`WorkshopCapacitiesIn`、`UserCapacitiesIn`、`EquipmentCapacitiesIn`)和自动派工(`AutoDispatchIn`)。
- `crud/production_plan.py`：纯函数式 CRUD，使用 `sqlalchemy.select` + `outerjoin` 聚合订单行项数量；`release_plan` 为关键业务入口，调用 `app.crud.order.create_work_orders_for_order` 与 `app.crud.plan_kitting.calc_order_kitting_shortages` 完成齐套检查与工单生成，并通过 `_count_order_tasks` 延迟导入 `Task`/`WorkOrder` 避免循环依赖。
依赖方向：crud → models + order/plan_kitting/order；schema 无运行时依赖；model 仅依赖 base 与关联实体。
