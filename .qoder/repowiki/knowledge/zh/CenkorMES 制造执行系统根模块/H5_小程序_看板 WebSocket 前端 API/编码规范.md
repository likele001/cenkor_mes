- 每个业务子模块暴露一个 `router = APIRouter(...)`，并在 `router.py` 中通过 `include_router` 集中注册，按 tags 分组便于文档分类。
- 需要员工角色的接口统一通过模块内 `_ensure_employee(user)` 检查角色集合是否包含 employee/leader，否则抛出 403。
- 数据库会话与当前用户通过 `Depends(get_db)` 和 `Depends(get_current_user)` 注入，避免在 handler 内直接创建 Session。
- 所有成功响应统一经 `core.response.ok()` 包装返回，错误路径使用 `HTTPException(status_code, detail=...)` 抛出。
- 对外查询接口普遍采用 `offset`/`limit` 分页参数，并限制 `ge(0)`、`le(200)` 等边界值。
- 写操作先调用 CRUD/service 层完成事务性写入，随后通过 `create_notification` 或飞书通知服务触发下游通知，最后 `db.commit()`。
