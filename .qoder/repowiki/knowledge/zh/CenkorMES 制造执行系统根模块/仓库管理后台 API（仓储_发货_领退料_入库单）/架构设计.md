模块以 FastAPI `APIRouter` 为入口，按子业务拆分为独立文件并通过 `router.include_router` 聚合：
- `router.py`：仓库主路由，挂载 `/warehouses`、`/stocks`、`/logs` 及导出接口，并 include 三个子模块；所有路由依赖 `require_permissions(["warehouse.manage"])`。
- `shipments.py`：发货单路由（prefix=`/shipments`），权限为 `order.manage`，发货时调用 `app.crud.warehouse.adjust_stock` 扣减库存并联动订单状态与飞书通知。
- `material_issues.py`：领料单与退料单的 CRUD 与状态机（创建→发料/确认→取消），通过 `app.crud.material_issue` 操作 `MaterialIssue` / `MaterialReturn` 模型。
- `warehouse_entries.py`：入库单（采购入库/退料入库/其他入库），校验 source_type 与关联单据后调用 `app.crud.warehouse_entry`。

依赖方向单向向下：API 层仅依赖 `app.core.deps`（认证/鉴权）、`app.core.response.ok`、`app.crud.*`（持久化）、`app.models.*`（ORM 模型）、`app.services.code_generator.resolve_code`（统一编码生成），不直接写 SQL（除少量存在性检查）。
