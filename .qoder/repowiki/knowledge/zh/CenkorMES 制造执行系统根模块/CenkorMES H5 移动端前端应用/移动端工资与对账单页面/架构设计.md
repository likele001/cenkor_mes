三个独立的 Vue 3 `<script setup>` 单文件组件，均位于 `frontend-h5/src/pages/` 下，作为路由级页面直接挂载到移动端应用：
- `WagesPage.vue`：通过 `@/api/tasks` 的 `getMySalary` / `getMySalarySummary` 拉取当月计件明细与汇总，使用 URL query `month` 驱动月份切换（前推/后推 + ActionSheet 选择），并跳转至 `/salary/slip`。
- `SalarySlipPage.vue`：调用 `getMySalarySlip` / `signMySalarySlip` / `rejectMySalarySlip`，在底部弹窗中使用原生 Canvas 手写签名，经 `uploadFile` 上传附件后提交；支持拒签流程及已签名图片预览。
- `CustomerStatementsPage.vue`：独立于工资模块，通过 `@/api/customer` 的 `listMyStatements` 实现按状态（draft/confirmed/paid）分页浏览客户对账单，跳转到命名路由 `customerStatementDetail`。
依赖方向单向：页面 → `@/api/*` 客户端 API → 后端 FastAPI 接口；页面之间仅通过 router 跳转耦合，无共享逻辑抽取。
