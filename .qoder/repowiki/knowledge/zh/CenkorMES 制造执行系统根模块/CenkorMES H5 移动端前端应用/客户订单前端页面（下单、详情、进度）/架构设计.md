三个独立的 Vue 3 `<script setup>` 单文件组件，分别对应路由 `customerOrder` / `customerOrderDetail` / `customerOrderProgress`：
- `CustomerOrderPage.vue`：入口聚合页，通过 `van-tabs` 切换「浏览目录」「我的订单」「账单」三个子视图；使用 `getCatalog` 加载 SKU/产品目录并支持按产品筛选与关键词搜索，`listMyOrders` 拉取订单列表，`placeOrder` 提交下单请求。
- `CustomerOrderDetailPage.vue`：订单详情页，通过 `route.params.id` 获取订单号，并行调用 `getMyOrderDetail` / `getOrderShipments` / `getOrderAfterSales` 聚合展示订单信息、发货记录与售后记录，并通过 `createAfterSale` 发起退货/换货/维修等售后申请。
- `CustomerOrderProgressPage.vue`：进度追踪页，调用 `getMyOrderProgress` 渲染工单与工序任务的多级进度条。

所有数据访问统一走 `@/api/customer` 模块的 TypeScript 类型导出（如 `CustomerSkuOut`、`CustomerOrderListItem`、`CustomerOrderDetail`、`ShipmentOut`、`AfterSaleOut`、`CustomerOrderProgress`），页面本身不持有业务状态持久化，仅做 UI 呈现与用户交互。页面间通过 `vue-router` 的命名路由跳转（`customerOrderDetail`、`customerOrderProgress`、`customerStatements`、`profile`）。
