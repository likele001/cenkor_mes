- API 函数统一通过 `apiGet`/`apiPost`/`apiPut` 调用，URL 一律以 `/h5/` 前缀开头，与后端 FastAPI 路由一一对应。
- 每个 API 文件将响应数据结构以 TypeScript interface/type 导出，并在函数签名中以泛型 `<T>` 标注返回类型，实现前后端类型同步。
- 需要较长超时时间的 AI 相关接口通过 `{ timeout: AI_TIMEOUT_MS }` 或常量 `AI_TIMEOUT_MS = 120_000` 显式覆盖默认超时。
- 路由元信息使用 `meta.title` 或 `meta.titleKey` 描述页面标题，其中 `titleKey` 走 i18n 翻译，`title` 为硬编码中文。
- 公开可访问的路由通过在 `meta` 中设置 `public: true` 标记，由路由守卫跳过鉴权检查。
