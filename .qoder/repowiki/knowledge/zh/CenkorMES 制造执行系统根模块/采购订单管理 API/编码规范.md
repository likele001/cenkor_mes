- 路由函数统一使用 `Depends(get_db)` 注入 SQLAlchemy Session 与 `Depends(get_current_user)` 注入当前用户，并在函数签名末尾声明。
- 对外响应一律通过 `from app.core.response import ok` 包装，错误路径使用 `HTTPException(status_code=4xx, detail="中文消息")` 抛出。
- 变更类接口（入库/退货/作废）在修改前保存 `old_status = po.status`，修改后调用 `write_op_log(db, request, user, module="purchase", action=..., object_type="PurchaseOrder", ...)` 记录审计日志。
- 涉及库存变动的操作统一调用 `adjust_stock(db, warehouse_id, sku_id, change_qty, biz_type="purchase_in"|"purchase_return", biz_id=po.id, remark=po.code)`，而非直接写库存表。
- 接口返回前通过 `get_purchase_order_by_id(order_id, with_items=True)` 重新加载完整对象，再经本地 `_out()` 转换器序列化为扁平字典，避免 ORM 懒加载问题。
- 业务校验失败时抛出 `ValueError` 或 `HTTPException(400)`，由上层统一转换为 HTTP 400 响应。
