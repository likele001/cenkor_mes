- CRM 对象的访问控制统一遵循「超级用户 / customer.manage → 全量；crm.sales → 仅 owner_user_id 匹配；否则拒绝」三段式判定逻辑。
- 对可选扩展模型（CrmLead/CrmQuotation/CrmContract/CrmCampaign/CrmSalesTarget）采用 try/except ImportError 延迟导入，未安装时置 None 并在调用处短路返回。
- SQL 作用域注入使用 `apply_*_scope(stmt, user, permission_codes)` 模式，返回修改后的 Select 实例，无权限时通过 `id == -1` 或 `False` 构造空结果集。
- 关联实体展示字典统一返回 {id, code, name, display_name} 四字段结构，display_name 通过对应 `*_display_name` 格式化函数生成。
