模块由两部分组成：
- 入口 `app/celery_app.py`：创建 Celery 实例（broker 默认回退到 Redis URL），注册 `celery` 队列，通过 `autodiscover_tasks(["app"])` 自动发现所有 task 包；在 `beat_schedule` 中定义两条固定 Cron（每日凌晨计件/时薪计算、每月1号汇总），并在 `DEFAULT_CRON_JOBS` 常量中暴露给 `/admin/cron-jobs/defaults` 与 `cron_job_seeder`。
- 任务包 `app/tasks/`：按业务域拆分为 `salary.py`（计件/计时工资计算、月度汇总、工资明细导出）、`production.py`（排产自动化流水线扫描）、`report_exports.py`（产量/良率报表导出）、`notify.py`（飞书消息推送）；`decorators.py` 提供 `@db_task` 装饰器统一注入 SessionLocal 并 commit/rollback/close；`_excel_utils.py` 与 `_sync_excel.py` 为导出类任务的共享工具（load_job/start_job/save_excel_and_finish/fail_job）。
依赖方向单向向下：tasks → app.crud / app.services / app.models / app.storage，不反向引用 API router；每个任务函数以 `@shared_task(name="<domain>.<op>")` 显式命名，便于 Beat 与外部调用定位。
