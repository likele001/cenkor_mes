模块以 `router.py` 为唯一入口：构建一个顶层 `APIRouter`（`api_router`），通过 `include_router` 将各业务子路由按 URL prefix 挂载到 `/auth`、`/files`、`/public-config`、`/admin/*`、`/dashboard`、`/h5`、`/ws`、`/crm-adapter`、`/feishu`、`/miniapp/auth`、`/ai` 等路径；所有 admin 类路由统一通过 `_admin_deps = [Depends(get_current_user)]` 注入登录校验。`v1/` 子包提供面向前端的基础能力：`auth.py` 暴露 `/login`、`/me`、`/profile`、`/password`，依赖 `app.crud.user`、`app.services.login_captcha`、`app.services.login_ratelimit` 和 `app.core.security` 完成 JWT 签发与登录限流；`captcha.py` 提供验证码生成；`files.py` 封装附件上传/下载，基于 `app.storage` 抽象（支持本地与远端双备份）并记录到 `Attachment` 模型；`public_config.py` 返回公司品牌信息与登录开关，供未登录前端读取；`push_monitor.py` 通过 Redis 队列长度与 `FeishuPushLog` 表统计飞书推送状态，使用 `require_permissions(['setting.manage'])` 做权限控制。依赖方向单向：router → services/crud/models/core.deps，不反向引用上层业务模块。
