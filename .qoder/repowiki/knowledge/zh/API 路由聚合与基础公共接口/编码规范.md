- 每个子路由文件导出一个 FastAPI `APIRouter` 实例（命名为 `router`），由 `router.py` 统一 `include_router` 挂载到对应 URL prefix。
- 需要鉴权的接口在 handler 参数中使用 `Depends(get_current_user)` 获取当前用户，并在 `router.py` 中通过 `dependencies=_admin_deps` 对整组 admin 路由批量注入。
- 成功响应统一通过 `app.core.response.ok(data)` 包装，错误则抛出 `HTTPException(status_code, detail=...)`。
- 数据库会话通过 `Depends(get_db)` 注入，写操作后显式调用 `db.commit()` 与 `db.refresh(obj)`。
- 对外暴露的 API 返回结构保持一致：成功用 `ok({...})`，监控类接口采用 `{code, msg, data}` 三字段结构。
