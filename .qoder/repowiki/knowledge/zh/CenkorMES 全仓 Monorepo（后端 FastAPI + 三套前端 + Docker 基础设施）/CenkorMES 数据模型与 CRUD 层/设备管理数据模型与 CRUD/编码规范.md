- ORM 实体继承 `app.models.base.Base`，字段使用 `Mapped[...]` + `mapped_column` 声明，时间字段默认值通过 `server_default=func.now()` 并在更新时 `onupdate=func.now()`。
- 对外接口采用 Pydantic 三件套命名：`*CreateIn` / `*UpdateIn` / `*Out`，其中 Out 类统一配置 `model_config = {"from_attributes": True}` 以支持 ORM 直出。
- CRUD 层以独立函数形式组织，遵循 `get_*` / `list_*` / `create_*` / `update_*` / `delete_*` 命名约定，查询统一使用 SQLAlchemy 2.0 `select()` 构建语句并通过 `offset`/`limit` 分页。
- 可选字段在 Pydantic 中使用 `str | None = None` 或 `int | None = None` 表示，必填字段通过 `Field(min_length=1, max_length=N)` 进行长度校验。
