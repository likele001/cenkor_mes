模块按三层划分：
- 模型层 `app/models/permission.py`：基于 SQLAlchemy ORM 的 `Permission` 表（code/name），通过 secondary 表 `role_permissions` 与 `Role` 建立多对多关系。
- Schema 层 `app/schemas/system_rbac.py`：使用 Pydantic v2 的 `BaseModel` + `Field` 定义 PermissionCreateIn/UpdateIn、RoleCreateIn/UpdateIn、RoleSetPermissionsIn、UserCreateIn/UpdateIn，覆盖创建、更新及角色权限绑定等入参校验。
- CRUD 层 `app/crud/rbac.py`：提供 `ensure_permissions`、`create_default_roles`、`get_user_permission_codes` 三个函数，依赖 `app.core.seed.DEFAULT_PERMISSIONS`、`DEFAULT_ROLES`、`ROLE_PERMISSION_PRESETS` 完成系统启动时的种子数据注入，并通过 `IntegrityError` 回滚处理并发插入冲突；用户权限码聚合通过延迟导入 `app.models.user.User` 避免循环依赖。
依赖方向：CRUD → models + core.seed；Schema 独立无运行时依赖；模型仅声明 ORM 关系。
