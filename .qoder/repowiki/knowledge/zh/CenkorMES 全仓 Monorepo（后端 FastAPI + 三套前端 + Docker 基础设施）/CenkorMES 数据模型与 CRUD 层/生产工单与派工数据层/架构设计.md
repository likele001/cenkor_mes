模块遵循 FastAPI + SQLAlchemy 2.0 ORM + Pydantic 的标准三层结构：
- `models/work_order.py`：声明 `WorkOrder` 表（`work_orders`），通过外键关联 `orders`、`order_items`、`products`、`skus`，并维护与 `Task`、`WorkOrderPiece` 的一对多关系；使用 `Mapped` / `mapped_column` 类型注解，`status` 默认 `open`，并通过 `UniqueConstraint(order_item_id)` 保证一个订单项仅对应一张工单。
- `schemas/work_order.py`：仅提供 `WorkOrderOut` 响应模型，用于 API 返回字段裁剪。
- `crud/work_order.py`：提供 `get_work_order_by_id`（可选 eager-load `tasks.process`）和 `list_work_orders`（支持按 `order_id`、`status` 过滤，分页 offset/limit，eager-load `sku.product` 与 `product`）两个查询入口。
依赖方向单向：CRUD → Model → Base，Schema 不反向引用 Model，保持 API 契约与持久化模型的解耦。
