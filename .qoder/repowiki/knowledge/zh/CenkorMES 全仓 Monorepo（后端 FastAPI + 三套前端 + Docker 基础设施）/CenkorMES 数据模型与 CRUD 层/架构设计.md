本模块是 FastAPI 应用的数据访问基座，采用三层对齐的目录结构：
- `app/models/`：每个业务子域（工单、计划、物料、质检、设备、RBAC、仓库、采购财务等）一个或多个 `.py` 文件，继承 `base.Base(DeclarativeBase)`；`__init__.py` 集中 import 所有 ORM 类并暴露 `__all__`，供 Alembic、demo_data、pytest 等脚本通过 `from app.models import *` 触发 mapper 配置。
- `app/schemas/`：对应模型的 Pydantic v2 输入/输出模式，命名与 models 一一对应，承担 API 入参校验与字段裁剪。
- `app/crud/`：基于 `sqlmodel.Session` 封装的增删改查函数，按领域拆分文件，被上层 `app/services` 调用。
跨子模块的耦合点集中在 `models/__init__.py`——它把分散的模型聚合为单一入口，解决 warehouse_entry/material_issue/supplier_statement 等模块通过字符串 relationship 引用 finance/purchase 导致的循环导入问题；同时该文件也是 Alembic 自动发现表结构的唯一入口。各子模块之间不直接互相 import，而是通过共享的 Base、Session 以及由 services 层编排的 CRUD 接口协作。
