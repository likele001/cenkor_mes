模块按三层组织：
- 数据模型层 `app/models/warehouse.py`：基于 SQLAlchemy 2.x Mapped Column 声明 `Warehouse`（仓库主数据，含 code 唯一约束）、`Stock`（仓库×SKU 维度的当前库存，含联合唯一约束）和 `StockLog`（正=入库、负=出库的流水表），均继承 `Base` 并带 `created_at`/`updated_at` 时间戳；通过外键关联 `warehouses` 与 `skus`。
- 持久化层 `app/crud/warehouse.py`：提供 `create_warehouse`、`list_warehouses`、`get_stock`/`get_or_create_stock`、`adjust_stock`（原子更新库存并追加一条 StockLog）、`list_stocks`/`list_stock_logs`（支持按 warehouse_id、sku_id、item_type=material/product 过滤）以及 `sum_stock_qty_by_sku_ids` 聚合查询。
- 接口层 `app/schemas/platform.py`：本模块实际未使用其中的 Pydantic Schema（该文件集中存放平台租户、SaaS 套餐、登录等无关 schema）。
依赖方向单向：crud → models；models 仅依赖 `app.models.base.Base` 与外部 `Sku` 模型，不反向依赖上层 API。
