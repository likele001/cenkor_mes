仓库采用前后端同仓 monorepo 结构：
- 后端以 `backend/app/api` 为路由入口，由 `backend_api_router` 统一注册 v1 子路由（认证、验证码、文件上传、公开配置、推送监控），所有管理端业务域共享 `backend_core`（配置/DB/Redis/JWT/RBAC/对象存储/Celery Beat）、`backend_models_schemas_crud`（SQLAlchemy + Pydantic + CRUD）与 `backend_services_tasks`（Celery 任务注册）。
- 前端分三套应用：`frontend_admin_pro`（Vue 3 管理后台）、`frontend_h5`（移动端 H5）、`lightmes_miniapp`（uni-app 小程序），均通过各自 API 客户端调用后端 `/api`、`/h5`、`/miniapp` 等前缀接口。
- 运行时由根 `docker-compose.yml` 编排 MySQL 8.0 + Redis 7 + backend + web-admin + web-h5 五服务，Nginx 在容器内将 `/api` 反代到 backend:8000；本地开发由根 `start.sh` 同时拉起 uvicorn（--reload）与两个 Vite dev server，端口默认 8000/5174/5173。
- 版本发布走根 `scripts/release-all.sh`，唯一版本号源为根 `VERSION` 文件，自动递增并追加 `backend/CHANGELOG.json`，后端启动时同步至 `system_versions` 表供关于页展示。
