模块由三个独立的 Vue 3 `<script setup>` 单文件组件组成，均位于 `frontend-h5/src/pages/` 下：
- `TasksPage.vue`：通过 `@/api/tasks.getMyTasks` 拉取分页任务（offset/limit=50），按 `pending/working/done` 状态筛选，结合 `van-pull-refresh` + `van-list` 实现下拉刷新与无限滚动；同时调用 `@/api.ai.getTaskRecommend` 展示 AI 推荐（急件/续报/剩最多）。
- `TaskDetailPage.vue`：根据路由参数 `id` 并行加载 `getTaskDetail` 与 `getTaskQr`，用 `svgToDataUrl` 将 SVG 二维码转为 img src，并提供复制任务码、跳转报工等动作。
- `GuidePage.vue`：纯静态文档型页面，以 `groups` 数组定义 29 个章节的侧边导航，配合滚动监听高亮当前 h2 锚点，无业务 API 调用。

依赖方向单向向外：页面 → `@/api/*`（后端 REST）、`@/utils/tenant`（租户路径前缀）、`@/utils/qr`（二维码转换）。所有跨租户路由统一经 `tenantH5Path` 包装，报工入口根据 `use_unit_report` 字段在 `/report` 与 `/report-unit` 之间切换。
