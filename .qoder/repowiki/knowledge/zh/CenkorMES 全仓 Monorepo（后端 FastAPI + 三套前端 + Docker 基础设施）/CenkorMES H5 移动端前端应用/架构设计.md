本模块是 CenkorMES 的前端 H5 子应用，采用 Vue 3 + TypeScript + Vite 构建，入口为 `src/main.ts`，由 `src/router/index.ts` 集中注册所有业务路由。
- 共享层：`app_shell_and_shared` 提供路由配置与各业务域的 HTTP 客户端封装（`src/api/*.ts`），`shared_ui_layers` 提供可复用组件（CameraPhotoCapture、FileUploader、ScanTaskCodeButton 等）、主题 composable（`composables/useTheme.ts`）以及摄像头/扫码/语音/HTTP/会话等浏览器能力适配工具（`src/utils/`）。
- 页面层：attendance_pages、reporting_pages、task_management_pages、customer_order_pages、wages_pages 等子模块均位于 `src/pages/`，仅通过 api 目录下的 typed client 调用后端 `/h5/*` 接口，不直接使用 fetch。
- 部署：Vite 产物经 nginx-h5.example.conf 或 `.htaccess` 静态托管，`public/trace.html` 作为独立溯源查询入口，其余页面走 SPA 404 回退。
