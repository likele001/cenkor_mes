本模块由三个独立的 Vue 3 `<script setup>` 单文件组件构成，均位于 `frontend-h5/src/pages/` 下，作为路由级页面直接挂载：
- `AttendancePage.vue`：考勤主页面，通过 `@/api/tasks` 的 `listMyAttendance` / `checkIn` / `checkOut` / `getAttendanceGeofence` 拉取本人打卡记录与地理围栏配置，在本地计算本月出勤天数、总工时、平均工时及今日打卡状态（未打卡/已上班未下班/已打卡），并通过 `van-button` + `van-tag` 展示打卡按钮与状态标签。
- `ReportHistoryPage.vue`：报工历史列表，调用 `@/api/reportUnits.getMyReportUnits` 获取本人报工单元，过滤掉 `draft` 草稿态后以 `van-list` 渲染任务码、件次、结果类型（good/bad→合格/不良）与审批状态映射（draft/submitted/leader_approved/qc_approved/rejected → 待报/待初审/待终审/已通过/已驳回）。
- `ReportManualPage.vue`：纯入口页，接收用户输入的任务码，经 `tenantH5Path('/report-unit')` 拼接租户路径后跳转到逐件报工页面并附带 `task_code` query。
依赖方向单向向外：页面仅消费 `@/api/*` 封装的 HTTP 客户端，不直接发起 fetch；UI 全部基于 Vant 4 组件（`van-button`/`van-list`/`van-cell-group`/`van-tag`/`van-field`/`van-empty`/`showToast`/`showLoadingToast`）。
