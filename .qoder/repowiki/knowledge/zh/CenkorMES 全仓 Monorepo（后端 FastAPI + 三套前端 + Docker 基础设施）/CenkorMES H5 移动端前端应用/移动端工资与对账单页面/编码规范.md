- 页面通过 `useRoute().query.month` 作为当前月份参数，并在 `onMounted` 与 `watch(route.query.month)` 中统一触发数据刷新。
- 异步数据加载封装为 `refresh()` / `load()` 函数，使用 `loading` ref 包裹 try/finally 以控制 loading 状态。
- 金额展示统一通过本地 `formatMoney(v.toFixed(2))` 函数格式化后再渲染。
- 跨页导航使用 `router.push` / `router.replace` 配合 query 或命名路由传递参数，而非字符串拼接路径。
