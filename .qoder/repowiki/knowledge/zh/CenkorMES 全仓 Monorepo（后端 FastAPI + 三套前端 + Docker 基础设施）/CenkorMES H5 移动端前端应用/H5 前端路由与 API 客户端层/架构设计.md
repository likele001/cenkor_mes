模块由两部分组成：
- `src/router/index.ts`：基于 vue-router 4 创建单例 router，使用 `createWebHashHistory()` 适配移动端浏览器；以 `/` 下挂载 `MainLayout` 作为主布局容器，子路由按功能分组（tasks、report、attendance、wages、customer、notifications 等），公开页面（/login、/guide、/trace）通过 `meta.public` 标记绕过鉴权。
- `beforeEach` 守卫集中处理认证流程：未登录重定向到 `/login` 并携带 `redirect` query；登录后根据 `auth.isCustomer` 分流至客户门户或生产端页面；同时根据 `to.meta.titleKey` 结合 i18n 设置文档标题。
- `src/api/` 下每个文件对应一个后端业务域（auth、tasks、customer、ai、feishu、files、captcha、reportUnits、settings、publicTrace），统一通过 `@/utils/http` 暴露的 `apiGet`/`apiPost`/`apiPut`/`http` 发起请求，所有 URL 均以 `/h5/...` 前缀对齐后端 FastAPI 路由。
- 依赖方向单向：router 仅依赖 store (`useAuthStore`) 和页面组件；api 模块不反向引用 router，仅依赖 `@/utils/http` 与类型定义，便于在 worker 或其他环境复用。
