- 后端枚举值（status、sale_type 等）在前端通过本地 `Record<string, string>` 映射到 i18n key（如 `customer.status.*`、`customer.afterSale.*`），未匹配时回退原始值。
- 百分比字段统一经 `toPercent(v)` 工具函数处理：先乘以 10000 再除以 100 四舍五入，并将结果钳制在 0~100 区间后传给 `van-progress`。
- 异步数据加载采用 `ref(loading)` + try/finally 模式，并在 `onMounted` 或 `watch(id, ..., { immediate: true })` 中触发，失败路径以空 catch 静默处理。
- 用户操作反馈统一使用 Vant 的 `showLoadingToast` / `showConfirmDialog` / `showDialog` / `showToast`，并在 finally 中调用 `closeToast()` 关闭加载提示。
- 路由跳转统一通过 `router.push({ name: 'xxx', params: { id } })` 的命名路由方式，而非直接拼接 URL。
