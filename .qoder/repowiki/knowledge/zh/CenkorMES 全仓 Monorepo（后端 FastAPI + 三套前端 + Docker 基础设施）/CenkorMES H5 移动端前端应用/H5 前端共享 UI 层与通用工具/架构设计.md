模块按职责分为三层：
- `components/`：基于 Vant 的 Vue 3 `<script setup>` 业务组件，包括文件上传 (`FileUploader.vue`)、拍照 (`CameraPhotoCapture.vue`)、录像 (`CameraVideoCapture.vue`)、任务码扫码按钮 (`ScanTaskCodeButton.vue`) 和空状态占位 (`Empty.vue`)，通过 `defineModel` / `defineEmits` 与父组件双向绑定。
- `composables/useTheme.ts`：暴露 `useTheme()` 组合式函数，管理 `light/dark` 主题并持久化到 `localStorage`。
- `utils/`：纯函数与类形式的浏览器能力适配层，依赖方向单向（组件 → utils → 浏览器 API），不反向依赖业务页面；其中 `http.ts` 基于 axios 创建带 Bearer token 拦截器的 Axios 实例，统一抛出 `ApiError`；`session-token.ts` 抽象 `localStorage`/`sessionStorage` 切换以支持「记住登录」；`camera.ts`、`voice-input.ts`、`parseTaskCode.ts`、`qr.ts`、`chunk-reload.ts`、`tenant.ts`、`vant-locale.ts` 各自封装一类原生能力或兼容逻辑。

依赖方向：组件仅依赖 `@/api/*` 与 `@/utils/*`，utils 之间相互独立，无循环依赖。
