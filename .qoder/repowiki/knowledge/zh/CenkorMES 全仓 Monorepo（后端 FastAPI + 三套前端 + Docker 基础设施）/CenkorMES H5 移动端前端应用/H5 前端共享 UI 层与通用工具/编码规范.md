- 组件统一使用 Vue 3 `<script setup lang="ts">`，并通过 `withDefaults(defineProps<...>())` 声明 props 及默认值。
- 跨组件数据同步采用 `defineModel` 或 `emit('update:modelValue', ...)` 的双向绑定模式，而非直接修改父组件 state。
- 浏览器原生 API（`BarcodeDetector`、`SpeechRecognition`、`MediaRecorder`、`getUserMedia`）在调用前进行特性检测与降级回退，不支持时给出用户提示。
- 工具函数保持纯函数导出，不持有全局可变状态；需要副作用（如安装事件监听）则通过独立的 `install*` 函数显式触发。
- 所有对外错误通过 `showToast` 反馈给用户，内部统一抛出自定义 `ApiError` 或普通 Error。
