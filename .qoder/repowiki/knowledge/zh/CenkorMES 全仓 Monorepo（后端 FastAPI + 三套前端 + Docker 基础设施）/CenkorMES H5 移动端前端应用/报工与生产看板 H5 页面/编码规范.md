- 所有异步 UI 反馈统一通过 Vant 的 `showToast` / `showDialog` / `showLoadingToast` 呈现，错误分支捕获后以 toast 提示而非抛错上冒。
- 语音报工采用「Web Speech API 优先 + 文字输入降级」双路径：先检测 `isVoiceInputSupported()`，失败则弹出 `van-overlay` 中的文字输入框，最终都走 `voiceParseReport` 解析。
- AI 能力（计数/缺陷分类/AI 检查）通过 `attachmentIdToUrl` 将本地上传 id 转为 URL 后调用 `@/api/ai` 对应接口，并在成功时回填 `form.good_qty` / `remark` / `result_type` 等字段。
- 深链直达场景下，组件在 `onMounted` 中读取 `route.query.task_code` 并直接触发 `loadTask`，同时用 `watch(route.query)` 监听参数变化重新加载。
- 跨租户路由跳转统一通过 `tenantH5Path('/report-unit')` 包装，避免硬编码绝对路径。
