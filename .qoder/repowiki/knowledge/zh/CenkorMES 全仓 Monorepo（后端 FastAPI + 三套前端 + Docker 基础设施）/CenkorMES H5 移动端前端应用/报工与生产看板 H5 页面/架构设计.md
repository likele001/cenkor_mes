三个同级 Vue 3 `<script setup>` 单文件组件，分别承担不同报工形态：
- `ReportWorkPage.vue`：批量报工入口，通过 `ScanTaskCodeButton` 或手动输入任务码调用 `@/api/tasks.getTaskDetail`，根据 `task.use_unit_report` 路由到 `ReportUnitPage`；表单聚合合格数/不良数/备注/附件，提交走 `submitReport`。
- `ReportUnitPage.vue`：件次级报工（unit_seq），调用 `getTaskUnits` + `submitReportUnit`，支持池化套号（`piece_pool_enabled`）、首道工序自动绑定成品码、异常拦截二次确认（`anomaly_warning` → `anomaly_confirmed=true` 重提）。
- `ScreenPage.vue`：只读看板，轮询 `getMyDashboardSummary` 展示良率、工资、任务进度等 KPI，15 秒刷新一次。

依赖方向单向向外：页面仅消费 `@/api/tasks`、`@/api/reportUnits`、`@/api/ai`、`@/api/files`、`@/api/settings` 等 API 层，UI 使用 Vant 4 组件与 Tailwind 类名，无内部子模块。
