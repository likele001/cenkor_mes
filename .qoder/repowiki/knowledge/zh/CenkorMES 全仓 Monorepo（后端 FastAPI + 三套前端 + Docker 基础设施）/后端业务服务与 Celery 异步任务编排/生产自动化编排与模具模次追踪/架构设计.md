模块由三个文件组成，职责分层清晰：
- `production_automation_settings.py` 定义 `KEY = "production.automation"` 及 `DEFAULTS`（含 `on_order_confirm`、`on_plan_saved`、`audit`、`briefing`、`alerts` 等子段），通过 `_merge_dict` 深度合并 tenant_settings JSON，暴露 `get_automation_settings` / `save_automation_settings`。
- `production_automation.py` 是编排入口：`precheck_order_for_automation` / `precheck_plan_for_automation` 做前置校验；`run_auto_schedule` 支持 backward/forward 两种工作日历排程；`apply_optimizer_dates` 委托 `app.services.planning_optimizer.optimize_plan_schedule`；`run_auto_release` / `run_auto_dispatch` 分别委托 `app.crud.production_plan.release_plan` 与 `app.services.plan_auto_dispatch.execute_auto_dispatch`；`run_schedule_pipeline` 串联 schedule → release → dispatch 三步，统一记录 `create_automation_log` 并通过 `notify_users_with_permission` + 飞书事件通知失败；`auto_create_plan_for_order` 在订单确认后按设置自动建计划并可选触发流水线；`enqueue_plan_pipeline` / `maybe_trigger_plan_automation` 通过 Celery 异步执行 `production.automation.pipeline`。
- `mold_shot_tracker.py` 当前为 Stub，仅导出占位函数，预留模具模次计数扩展点。
依赖方向单向向外：本模块调用 CRUD、其他 services（plan_auto_dispatch、planning_optimizer、plan_readiness）、Celery 与通知子系统，不被同层反向引用。
