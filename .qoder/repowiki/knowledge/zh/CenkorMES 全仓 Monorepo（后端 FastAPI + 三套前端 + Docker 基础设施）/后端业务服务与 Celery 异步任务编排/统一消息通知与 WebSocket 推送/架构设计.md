模块由三层组成：
- 通道定义层 `notify_channels.py`：通过 `Channel`、`TargetKind` 枚举和 `PushTarget` 工厂统一描述推送目标；用 `PERSONAL_EVENTS` / `GROUP_ONLY_EVENTS` / `MIXED_EVENTS` / `RULE_BASED_EVENTS` 四个 frozenset 对事件进行静态分类，并维护 `EVENT_GROUP_CODES` 将事件映射到管理/生产/工厂群。
- 分发调度层 `notify_dispatcher.py`：对外暴露 `dispatch()` 入口，依据事件分类分别走个人（查 `User.feishu_open_id`）、群组（解析飞书配置中的 `groups[].channels.feishu.chat_id`）、规则驱动（调用 `app.services.feishu.targets.resolve_targets`）或混合路径；每条待发送记录写入 `FeishuPushLog` 并通过 `enqueue_after_commit()` 在 SQLAlchemy `after_commit` 回调中经 Celery `feishu.send_message` 任务异步投递，避免 worker 在新 session 下查不到尚未 commit 的 log。
- 实时推送层 `ws_hub.py`：`DashboardWSHub` 以进程内 `set[WebSocket]` + `asyncio.Lock` 维护大屏客户端连接，提供 `connect/disconnect/broadcast` 方法，模块级单例 `dashboard_ws_hub` 供其他服务广播刷新事件。
依赖方向单向：dispatcher → channels + feishu settings/targets + celery；ws_hub 独立无外部业务依赖。
