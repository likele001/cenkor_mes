模块以 `client.py` 为底层 HTTP 抽象层（基于 httpx + Redis 缓存 tenant_access_token），向上提供业务子能力：
- 配置与凭据：`settings.py` 通过 `tenant_settings` 表（KEY=`feishu.notify`）管理 app_id/secret/encrypt_key/verification_token、群组、事件规则、静默时段等，并提供 `get_feishu_credentials` 回退到环境变量 `FEISHU_APP_ID/SECRET`。
- OAuth 用户绑定：`oauth.py` 使用系统 JWT 生成 bind state，调用飞书 OIDC 换取 open_id 写入 `User.feishu_open_id/user_id/union_id`。
- 事件回调与卡片动作：`callbacks.py` 实现 AES-CBC+PKCS7 解密、URL verification、`im.message.receive_v1` 与 `card.action.trigger` 路由；卡片动作经 `audit_actions.py` 委派给 `app.services.report_audit_actions.handle_audit_action`。
- 消息构建与投递：`cards.py` 构造飞书 interactive card JSON；`notify.py` 作为对外入口，按 `rules[event_code]` 解析目标（员工/部门/群组/权限组），通过 `targets.py` 解析、`links.py` 拼装 H5/后台链接、`quiet_hours.py` 做静默时段延迟，最终写入 `FeishuPushLog` 并由 `notify_dispatcher.enqueue_after_commit` 异步派发。
- 诊断与检查：`delivery.py` 聚合机器人信息、租户名、用户 profile、P2P 聊天统计用于排障；`setup_check.py` 查询开放平台应用版本的事件订阅与 scope，输出引导步骤。
依赖方向单向向下：业务层 → client/settings/targets → 外部飞书 API；不直接依赖 FastAPI router，由上层 `app/api` 挂载。
