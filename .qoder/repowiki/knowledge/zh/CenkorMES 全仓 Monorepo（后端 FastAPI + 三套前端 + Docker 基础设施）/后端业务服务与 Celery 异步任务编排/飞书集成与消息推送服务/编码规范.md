- 所有飞书 Open API 调用统一经过 `client.py` 的 `get_tenant_access_token` 获取 token，并通过 `_feishu_request_json` 将非 code=0 响应转换为 `FeishuApiError`。
- HTTP 请求统一使用 `with httpx.Client(timeout=...)` 上下文管理器，避免连接泄漏。
- 配置项读取走 `settings.get_feishu_settings_raw` 合并 `DEFAULTS`，敏感字段（app_secret/encrypt_key/verification_token）在 admin 视图返回时掩码为 `********`。
- 事件分发通过 `emit_feishu_event` 进入统一 dispatcher 并传入 `restrict_channel="feishu"`，避免与其他 IM 通道重复产生日志。
- 卡片按钮携带的 action 值统一用 `_button` 辅助函数序列化为 `{action, biz_type, biz_id}` JSON 字符串，回调端再反序列化交由 `handle_card_action` 处理。
- 对外暴露的 notify_* 函数（如 `notify_dispatch_assigned`、`notify_report_submitted`）只负责组装 event_code/title/content/biz 参数，具体投递逻辑下沉到 `emit_feishu_event`。
