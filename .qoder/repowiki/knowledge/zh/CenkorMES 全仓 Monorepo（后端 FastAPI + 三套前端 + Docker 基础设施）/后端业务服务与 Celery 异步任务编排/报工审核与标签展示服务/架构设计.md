本模块由三个职责独立的 service 文件组成，均位于 backend/app/services/ 下：
- report_audit_actions.py：定义 ReportAuditError 异常与 leader_approve_report / reject_report / leader_approve_unit / reject_unit 四个审核函数，并通过 handle_audit_action 统一路由 action+biz_type 到具体实现；依赖 app.crud.report、app.crud.report_unit、app.crud.notification 完成状态变更与通知，权限校验通过 _has_report_audit 调用 app.services.feishu.targets._users_with_permission 动态加载。
- product_label_print.py：build_product_trace_labels_html 接收 WorkOrder + WorkOrderPiece 列表，借助 trace_qr_payload 生成二维码 SVG，按 LABELS_PER_PAGE=10、COLS=2 分页拼接 A4 打印 HTML（含 @page 样式）。
- display_label.py：纯展示层工具集，product_display_name / sku_display_name / sku_model_label / order_sku_option_label / process_display_name / material_display_name / party_display_name 等函数将内部编码（SW-P、SW-M 前缀）与结构化描述「颜色:…；规格:…」解析为对外可读的展示名，过滤「1」「0」「-」等无意义占位值。
依赖方向单向向外：本模块被 IM 审核入口、订单/报工前端渲染等上层调用，自身不暴露 API。
