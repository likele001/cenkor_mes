- 任务函数统一使用 `@shared_task(name="<domain>.<op>")` 显式声明任务名，便于 Beat 与外部系统引用。
- 任务内数据库访问通过 `from app.core.db import SessionLocal` 手动获取 session，并在 try/except/finally 中 commit/rollback/close。
- 对仅需简单 DB 读写的任务使用 `@db_task` 装饰器，让框架自动注入 db 参数并管理事务生命周期。
- 长耗时导出任务遵循 load_job → start_job → 构建 Workbook → save_excel_and_finish 的四步模板，失败路径统一走 fail_job。
- 任务返回值统一为 dict，成功携带 `{ok: True, ...}`，异常捕获后返回 `{ok: False, error: str(e)[:500]}` 并记录日志。
