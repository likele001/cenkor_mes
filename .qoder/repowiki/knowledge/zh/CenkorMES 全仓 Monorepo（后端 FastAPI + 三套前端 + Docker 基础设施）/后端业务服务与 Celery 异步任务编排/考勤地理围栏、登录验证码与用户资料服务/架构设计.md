本模块由三个独立的轻量 service 文件组成，均位于 backend/app/services/ 下，作为上层 router/crud 的纯函数式业务辅助层：
- attendance_geofence.py：通过 tenant_settings 表中的 KEY=`attendance.geofence` 读取经纬度与半径配置，使用 Haversine 公式计算距离并抛出 ValueError 进行越界拦截。
- login_captcha.py：基于 platform_setting 表的 `login_captcha_enabled` 布尔开关决定是否启用验证码，未启用时直接放行；启用后委托 app.services.captcha.verify_captcha 完成校验，失败返回 HTTPException(400)。
- profile.py：仅做 ProfileUpdateIn schema 到 dict 的白名单映射（full_name / phone / email），通过 model_dump(exclude_unset=True) 实现仅更新显式传入字段的增量更新语义。
依赖方向单向向下：本模块不反向被 CRUD 调用，而是被 API 层或 CRUD 层消费；所有持久化访问都委托给 app.crud.tenant_setting.get_setting 与 app.crud.platform_setting.get_bool_setting，自身不持有 ORM 模型定义。
