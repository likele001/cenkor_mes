- 构建前端镜像：`docker compose build web-admin web-h5`（依据 docker-compose.yml）。
- 离线部署：`bash docker/scripts/export-images.sh [输出目录]` 导出全部镜像，目标机执行 `docker load < dist-images/cenkormes_images_*.tar.gz` 后 `docker compose up -d`。
- 注入演示数据：`bash docker/scripts/init-demo.sh [容器名]`，默认自动探测 `cenkormes-backend` 容器并执行 `scripts/seed_demo.py`。
- 后端镜像支持 `PIP_INDEX_URL` 构建参数切换 pip 源（如清华源）。
