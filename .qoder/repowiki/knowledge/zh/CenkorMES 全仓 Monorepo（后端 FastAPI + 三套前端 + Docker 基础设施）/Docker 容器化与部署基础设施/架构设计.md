模块按运行时角色划分：
- 后端镜像 `backend/Dockerfile` 基于 `python:3.11-slim`，安装 PyMySQL（纯 Python，无需 mysqlclient/gcc）与 OpenMP 依赖 `libgomp1`，通过 `docker/scripts/entrypoint-api.sh` 等待 MySQL 就绪后 exec uvicorn；`CMD` 指向 `app.main:app`。
- 前端镜像 `docker/frontend/Dockerfile` 采用 Node 20 + Nginx 双阶段构建，通过 `--build-arg FRONTEND` 在 `frontend-admin-pro` / `frontend-h5` 两个源码目录间切换，产物由对应 `docker/nginx/{frontend-admin-pro,h5}.conf` 托管。
- Nginx 配置统一将 `/api/` 反代到 `http://backend:8000/api/`，静态资源开启 1 年 immutable 缓存，SPA 路由回退到 `index.html`，并设置 `X-Content-Type-Options` / `X-Frame-Options` 安全头。
- 运维脚本集中在 `docker/scripts/`：`export-images.sh` 打包 backend/web-admin/web-h5/mysql:8.0/redis:7-alpine 五个镜像为 tar.gz 供内网导入；`init-demo.sh` 调用容器内 `scripts/seed_demo.py` 幂等注入演示数据。
- `backend/.htaccess` 为 Apache 伪静态占位文件，当前为空，实际部署走 Nginx。
依赖方向单向：前端镜像依赖后端服务名 `backend`，不反向依赖后端代码。
