- 每个子模块暴露一个 `router = APIRouter(...)`，并在 `router.py` 中通过 `include_router` 挂载到仓库主路由下。
- 路由级权限通过 `dependencies=[Depends(require_permissions([...]))]` 声明，仓库类接口统一使用 `warehouse.manage`，发货单使用 `order.manage`。
- 请求体使用 Pydantic `BaseModel` + `Field(ge=1, max_length=...)` 做参数校验，列表查询统一带 `offset`/`limit` 分页参数。
- 响应统一经 `app.core.response.ok({...})` 包装返回，字段映射由模块内 `_out` / `_entry_out` / `_issue_out` 等私有函数完成。
- 业务单号通过 `resolve_code(db, biz_type=BizType.X, code=payload.code, exists=lambda c: ..., duplicate_msg="...")` 生成或校验唯一性。
- 状态变更接口（发料/确认/取消/签收等）先查实体再调用对应 service 方法，捕获 `ValueError` 转为 HTTP 400，成功后 `db.commit()` 并返回最新记录。
