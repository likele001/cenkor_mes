- 后端每个业务域在 `app/api` 下独立 router 文件，由 `backend_api_router` 统一挂载到 `/api/v1/<domain>` 路径前缀
- 数据库模型集中放在 `backend/models`，Pydantic Schema 与 CRUD 函数按域拆分并在 `app/models/__init__.py` 统一注册导入
- 异步任务统一在 `backend/services/tasks/celery_app.py` 中注册，由 Celery Beat 调度执行
- 前端各应用通过统一的 API 客户端封装后端接口，按角色（admin/h5/miniapp）区分请求前缀
