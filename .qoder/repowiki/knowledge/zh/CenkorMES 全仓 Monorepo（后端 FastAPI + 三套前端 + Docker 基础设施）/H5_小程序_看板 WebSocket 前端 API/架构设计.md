模块由三个并列的 FastAPI 子路由组成，统一挂载到上层 app：
- `h5/`：通过 `router.py` 聚合 tasks、attendance、customer、report_units、salary_slips、notifications、settings_media、feishu、public_trace 等子路由，按业务域划分文件；其中 `public_trace.py` 挂载在 `/public` 前缀下无需鉴权，其余接口依赖 `get_current_user`。
- `miniapp/auth.py`：独立的小程序登录入口，固定 tenant_id=1，通过 httpx 调用微信 jscode2session 换取 openid，再绑定系统用户并签发 JWT。
- `ws/dashboard.py`：基于 FastAPI `WebSocket` 实现大屏看板通道，通过 Query 参数 token 校验身份后接入 `app.services.ws_hub.dashboard_ws_hub` 进行广播。

依赖方向单向向下：API 层仅负责入参校验、权限判断与响应封装，数据访问委托给 `app.crud.*`，业务规则（如报工模式、地理围栏、飞书通知）下沉至 `app.services.*`，模型定义位于 `app.models.*`。
