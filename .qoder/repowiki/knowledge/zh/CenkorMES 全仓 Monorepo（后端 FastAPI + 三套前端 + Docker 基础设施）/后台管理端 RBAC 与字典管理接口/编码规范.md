- 每个资源模块以 `router = APIRouter(dependencies=[Depends(require_permissions(["xxx.manage|"]))])` 声明路由级权限，再在 handler 内用 `get_current_user` 注入当前用户。
- 写操作在调用 CRUD 后统一通过 `write_op_log(db, request, user, module=..., action=..., object_type=..., object_id=..., detail=...)` 记录审计日志，随后 `db.commit()`。
- CRUD 返回值统一通过 `core.response.ok({...})` 包装，错误路径直接 `raise HTTPException(status_code, detail=...)`。
- 对外输出字段通过模块内 `_out` / `_role_out` / `_department_out` 等小型转换函数从 ORM 对象映射为 dict，避免在路由中散落字段选择逻辑。
- 新增资源时在 `system/router.py` 中以 `include_router(router, prefix="/<resource>", tags=["admin-system-<resource>"])` 注册，tags 采用 `admin-system-<资源名>` 命名约定。
