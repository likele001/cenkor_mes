模块由两个并列的 FastAPI 子路由组成：
- `reports/router.py`：注册 `/defect-pareto`、`/production`、`/yield`、`/process-rank`、`/daily-trend` 等统计接口，并挂载 `purchase.py` 子路由（`/purchase`）。查询逻辑下沉到 `app.crud.report_stats`（`get_production_summary`、`get_yield_summary`、`get_process_rank`、`get_daily_trend`），使用 SQLAlchemy Core `select()` + `func` 聚合；缺陷 Pareto 直接 join `InspectionRecord` 与 `DefectCode`。
- 异步导出通过 `app.crud.export_job.create_export_job` 写入 `ExportJob` 模型后调用 `celery.send_task("report.production_excel"|"report.yield_excel")`，并提供 `/export-jobs` 列表接口统一轮询。
- `shift/router.py`：按权限 `attendance.manage` 暴露班次（CRUD）与排班（含批量创建 `/schedules/batch`）接口，业务逻辑委托给 `app.crud.shift`，入参校验走 `app.schemas.shift`，编码生成复用 `app.services.code_generator.resolve_code(BizType.EQUIPMENT)`。
- 依赖方向：router → crud/schemas/services/core.deps，不直接操作 ORM 模型（除 reports 内少量 inline SQL）；所有响应经 `core.response.ok` 包装。
