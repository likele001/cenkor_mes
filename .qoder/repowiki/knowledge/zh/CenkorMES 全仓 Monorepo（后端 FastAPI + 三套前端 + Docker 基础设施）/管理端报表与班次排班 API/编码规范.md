- 路由层通过 `APIRouter(dependencies=[Depends(require_permissions([...]))])` 声明权限，再在 handler 中用 `Depends(get_current_user)`、`Depends(get_db)` 注入当前用户与数据库会话。
- 所有成功响应统一使用 `core.response.ok(data)` 包装返回，错误路径通过 `HTTPException(status_code, detail=...)` 抛出。
- 复杂查询与数据组装下沉到 `app.crud.*` 模块，router 仅负责参数解析、权限/DB 注入与结果封装。
- 可选日期范围参数采用 `date_from: date | None = Query(default=None)` 形式，并在函数体内以 `d_from or (today - timedelta(days=30))` 给出默认值。
- 新增导出能力遵循固定模式：先 `create_export_job` 持久化任务，再 `celery.send_task(task_name, args=[job.id])` 提交 Celery 任务，最后返回 job 对象。
