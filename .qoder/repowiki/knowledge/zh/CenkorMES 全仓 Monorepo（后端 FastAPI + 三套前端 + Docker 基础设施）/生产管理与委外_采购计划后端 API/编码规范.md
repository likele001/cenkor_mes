- 每个业务子模块以独立的 `APIRouter` 暴露，并在父 `router.py` 中通过 `include_router(prefix=..., tags=[...])` 集中装配。
- 路由函数统一使用 `Depends(get_db)` 和 `Depends(get_current_user)` 注入 Session 与 User，并通过 `require_permissions([...])` 作为 router 或单个 endpoint 的 dependency 做权限校验。
- 所有成功响应经 `ok({...})` 包装返回，参数校验失败或资源不存在通过 `HTTPException(status_code=400/404, detail=...)` 抛出。
- 对外数据结构通过模块内 `_out` / `_item_out` / `_order_brief` 等私有转换函数从 ORM 模型映射为 dict，避免直接暴露模型字段。
- 批量写入类接口（MRP compute、委外创建/状态变更/收发日志）采用 try/except ValueError → HTTPException(400) 的模式，并在成功后显式 `db.commit()`。
- 查询接口统一支持 `offset`/`limit` 分页以及可选的过滤 Query 参数（status、keyword、supplier_id 等），limit 默认 50 且上限 200。
