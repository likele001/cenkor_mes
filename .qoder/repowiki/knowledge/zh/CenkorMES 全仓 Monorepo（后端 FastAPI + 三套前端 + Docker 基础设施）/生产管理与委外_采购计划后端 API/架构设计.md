模块由三个并列的 FastAPI 子路由组成，统一挂载在 `app/api/admin` 下：
- `production/`：`router.py` 聚合 customers/orders/work-orders/tasks/assignments/reports/report_units/salary_reports/quality/crm 等子模块，每个文件一个 `APIRouter`，通过 `prefix` + `tags`（如 `admin-production-*`）注册；权限集中在各子 router 上通过 `dependencies=[Depends(require_permissions([...]))]` 声明（如 `work.manage`、`plan.manage`、`task.manage`、`dispatch.manage`）。
- `mrp/router.py`：独立实现 MRP 计算接口（list / compute / detail），直接调用 `app.crud.mrp.compute_mrp` 并返回计划及展开项。
- `subcontract/router.py`：实现委外订单 CRUD、状态流转、发料/收货日志，依赖 `app.crud.subcontract`。

依赖方向单向向下：router → `app.crud.*`（数据访问）→ `app.models.*`（SQLAlchemy ORM）；复杂业务逻辑下沉到 `app.services.*`（如 `dispatch_candidates`、`plan_capacity_settings`、`product_label_print`、`trace_public`、`task_qr`）。响应统一经 `app.core.response.ok` 包装，异常经 `HTTPException(status_code=400/404)` 抛出。数据库会话通过 `get_db` 注入，当前用户通过 `get_current_user` 注入。
