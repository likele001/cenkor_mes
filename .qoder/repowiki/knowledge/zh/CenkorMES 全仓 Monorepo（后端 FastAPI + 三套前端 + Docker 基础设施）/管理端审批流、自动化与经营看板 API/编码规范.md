- 每个子模块以 `router.py` 作为唯一 FastAPI 路由入口，Pydantic 请求模型就近定义在 router 内，响应体统一经 `ok()` 封装返回。
- 路由级或方法级通过 `Depends(require_permissions([...]))` 声明权限点，不同资源使用不同的权限标识（如 `setting.manage`、`plan.manage`、`exec_dashboard.view`）。
- 数据库会话通过 `Depends(get_db)` 注入，写操作在 CRUD 调用后显式 `db.commit()` 并可选 `db.refresh`。
- 对外字典序列化通过模块内 `_xxx_out` 辅助函数集中映射 ORM 字段，避免在视图函数中散落字段选择。
