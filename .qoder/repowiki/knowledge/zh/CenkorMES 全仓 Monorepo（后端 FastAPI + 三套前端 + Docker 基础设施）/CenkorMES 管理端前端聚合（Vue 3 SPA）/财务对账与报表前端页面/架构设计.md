本模块为 Vue 3 `<script setup>` 单文件组件集合，每个 `.vue` 文件对应一个路由页面：
- 列表页：`LedgersPage.vue`（总账）、`CustomerStatementsPage.vue`（客户对账单）、`SupplierStatementsPage.vue`（供应商对账单）、`PayablesPage.vue`（应付汇总）。
- 详情页：`CustomerStatementDetailPage.vue`、`SupplierStatementDetailPage.vue`。
- 报表页：`ProfitPage.vue`（按月的收入/成本/毛利及按客户/供应商拆分）。
所有页面通过 `@/api/finance` 暴露的 `financeApi` 调用后端 FastAPI 接口；部分页面额外依赖 `@/api/production`（获取客户下拉）和 `@/api/materials`（获取供应商下拉）。UI 统一基于 Element Plus 的 `el-table` + `el-pagination` 分页，并通过 `AdminPage` 布局组件承载标题与动作区。移动端采用 `hidden lg:block` 配合 `admin-mobile-row` / `admin-mobile-kv` 类名实现双模板渲染。状态标签通过 `useStatus('customer_statement'|'purchase_statement')` 从全局状态映射获取。
