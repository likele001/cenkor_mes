- 列表页统一使用 `reactive({ offset, limit })` 驱动分页，并通过 `page = Math.floor(offset / limit) + 1` 与 `fakeTotal = offset + items.length + (items.length === limit ? limit : 0)` 计算页码与假总数。
- 金额展示统一由本地 `formatMoney(v)` 函数处理 null/NaN 并 `Number(v).toFixed(2)` 输出两位小数。
- 业务状态标签通过 `useStatus(entityKey)` 组合式函数获取 `label` 与 `type`，再绑定到 `el-tag`。
- 需要关联实体的下拉选择（客户/供应商）在 `onMounted` 中预加载至内存 Map，再用 `partyOptionLabel` 或自定义 label 函数渲染。
- 详情/操作按钮所在页面使用 try/finally 包裹 loading 标志位，并在成功后调用 `reload()` 刷新数据。
