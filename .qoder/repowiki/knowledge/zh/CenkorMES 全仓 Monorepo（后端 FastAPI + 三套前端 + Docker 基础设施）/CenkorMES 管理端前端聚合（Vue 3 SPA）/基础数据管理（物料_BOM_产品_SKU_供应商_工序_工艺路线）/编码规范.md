- CRUD 页面统一采用 `dlg = reactive({ open, id, saving, form })` 模式管理对话框状态，新增时 `id=null`，编辑时回填 `row` 字段到 `form`。
- 列表查询使用 `reactive({ keyword, offset, limit, include_inactive })` 作为分页参数，并通过 `onMounted(() => reload(true))` 初始化加载。
- 禁用操作统一包裹在 `el-popconfirm` 中，按钮根据 `row.is_active` 控制 disabled，成功后调用 `reload(false)` 刷新。
- Excel 导出统一实现为 `exporting` ref 防抖 + `URL.createObjectURL(blob)` + `a.click()` + `URL.revokeObjectURL` 的标准下载流程。
- 新增时通过 `previewNextCode('xxx')` 预取编码前缀，提交时用 `codeForSubmit(code)` 生成最终 code，避免重复。
- 所有用户可见文案通过 `t('master.<entity>.<key>')` 从 i18n 命名空间读取，不使用硬编码字符串。
