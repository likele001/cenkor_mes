模块由一组并列的 Vue 3 `<script setup>` 单文件组件构成，每个 `*Page.vue` 对应一个后端实体（Products/Materials/Boms/Skus/Suppliers/Processes/ProcessRoutes/ProcessPrices/SkuBatchWithPrices），无内部子目录或共享逻辑。
- UI 层：统一使用 `AdminPage` 作为页面容器，列表用 `el-table` + `el-pagination`（部分复用 `AdminDataTable` 与 `useListPage` composable），编辑通过 `el-dialog` + `el-form` 弹窗完成；移动端以 `admin-mobile-row` / `admin-mobile-kv` 类名渲染卡片式布局。
- API 层：按领域拆分调用 `@/api/master`（product/sku/bom 等）与 `@/api/materials`（material/supplier/bom 等），所有请求走 typed Axios client，返回类型在 `ProductOut`、`MaterialOut`、`BomOut` 等处声明。
- 业务边界：BOM 是唯一跨实体的复杂表单，通过 `materialsApi.getBomFormOptions()` 预加载 SKU/Product/Material 下拉选项，并支持 global/product/sku 三种 scope 以及 copy-to-sku 操作；其余 CRUD 页面保持扁平结构。
- 依赖方向：页面 → `@/api/*` → 后端 FastAPI；页面之间不互相 import，仅通过路由参数（如 `router.push({ name: 'master-skus', query: { product_id } })`）进行跳转联动。
