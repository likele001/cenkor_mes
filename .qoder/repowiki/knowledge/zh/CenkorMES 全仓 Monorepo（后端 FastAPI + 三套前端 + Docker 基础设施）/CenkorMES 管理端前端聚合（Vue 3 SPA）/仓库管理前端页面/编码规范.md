- 页面统一以 `<AdminPage :title="t('warehouse.xxx.title')">` 包裹，所有用户可见文案通过 `useI18n()` 的 `t('warehouse.xxx.key')` 取国际化值。
- 表格列表采用桌面端 `el-table` 与移动端 `admin-mobile-row` 双模板并列渲染，并通过 `hidden lg:block` 控制显示。
- 异步加载遵循 try/finally 模式：在 `try` 中赋值 `items.value = res.items ?? []`，在 `finally` 中重置 `loading.value`，避免异常时卡住 loading。
- 需要二次确认的危险操作（确认入库、取消、确认领料、发货、签收等）统一通过 `ElMessageBox.confirm` 弹出确认框后再发起 API 调用。
- 表单提交前进行字段校验并在失败时通过 `ElMessage.warning` 提示，成功后 `ElMessage.success` 并刷新列表。
- 涉及多行明细的单据（入库单、领料单、发货单）使用响应式数组 `form.rows` / `form.items`，并提供 `addRow` / `removeItem` 动态增删行。
