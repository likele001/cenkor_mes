本模块为 Vue 3 `<script setup>` + TypeScript 的单文件组件集合，每个 `.vue` 文件对应一个后台管理路由（WarehousesPage / StocksPage / WarehouseEntriesPage / MaterialIssuesPage / MaterialReturnsPage / ShipmentsPage），统一通过 `@/components/admin/AdminPage.vue` 作为页面外壳。

- 数据访问分两条路径：基础 CRUD（如 WarehousesPage）直接调用 `@/utils/http` 的 `http.request` / `http.get` / `http.downloadBlob` 请求 `/admin/warehouse/*` REST 接口；业务单据类页面（Stocks、WarehouseEntries、MaterialIssues、MaterialReturns）则通过 `@/api/warehouse` 暴露的 `warehouseApi`（含 `listWarehouses`、`listStocks`、`listLogs`、`createEntry`、`confirmEntry`、`cancelEntry`、`listIssues`、`issueMaterials`、`cancelIssue` 等）进行类型安全的调用，并引入 `@/api/materials` 获取物料下拉选项。
- 状态机展示使用 `@/utils/status-maps` 的 `useStatus('shipment')` 或本地 `statusMap`/`sourceTypeMap` 常量将后端枚举（draft/confirmed/cancelled/pending/shipped/sign…）映射为 Element Plus tag 颜色与中文文案。
- 导出统一走 `@/composables/useExport`（StocksPage）或直接 `http.downloadBlob`（WarehousesPage）下载 Excel。
- 依赖方向：页面 → `@/api/warehouse` / `@/api/materials` → 后端 FastAPI `/admin/warehouse/*` 路由；页面之间无相互引用，彼此独立。
