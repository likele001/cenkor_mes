本目录是 CenkorMES 管理端的前端聚合层：`src/main.ts` 启动应用并挂载 Pinia、vue-i18n、Element Plus、Tailwind；`src/router/index.ts` 集中声明所有路由，将各子模块页面按 `/system-*`、`/master-*`、`/production-*`、`/purchase-*`、`/warehouse-*`、`/finance-*`、`/dashboard/*`、`/reports` 前缀组织到 `AppLayout.vue` 下，并通过 `meta.permissions` 配合 `src/stores/auth.ts` 的 `hasAnyPermission` 做后端 RBAC 校验，未登录或无权限重定向至 `/login`；`src/api/*.ts` 按后端 FastAPI 模块一一对应，页面侧仅 import 函数而不直接拼接 URL，HTTP 封装在 `src/utils/http.ts`；公共 UI 能力由 `src/components/admin/`（AdminPage/AdminDataTable/AdminFilterBar 等）、`src/composables/`（useListPage/useExport/useTheme 等）与 `src/layouts/AppLayout.vue` 提供，被所有业务子模块复用；`vite.config.ts` 通过 `manualChunks` 将 Element Plus、echarts、zrender、vue 等第三方库拆为独立 vendor chunk，开发环境通过代理 `/api` 转发到 `VITE_API_PROXY`（默认 `http://127.0.0.1:8000`）。
