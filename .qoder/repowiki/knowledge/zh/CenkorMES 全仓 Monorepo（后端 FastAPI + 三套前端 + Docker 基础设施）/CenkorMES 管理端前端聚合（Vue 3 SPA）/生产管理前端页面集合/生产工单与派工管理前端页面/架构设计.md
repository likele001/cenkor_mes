三个同级 Vue SFC 页面，均基于 `@/components/admin/AdminPage.vue` 作为布局壳，通过 `@/api/production` 中的 `productionApi` 调用后端 REST API：
- `WorkOrdersPage.vue`：工单列表 + 详情弹窗（内嵌该工单的工序任务子表），支持按订单号/状态筛选、分页、导出 Excel、批量打印成品追溯码（`printProductLabels`）。
- `TasksPage.vue`：任务列表 + 派工对话框，含技能筛选、远程搜索员工、设备选择；通过 `setTaskAssignments` 提交多行派工明细并校验重复/超量；支持单条/批量打印任务标签、导出 PDF 标签。
- `AssignmentsPage.vue`：派工明细视图，展示员工×工序维度的已报/待报数量与进度条，提供生成/下载 SVG 二维码、打印标签、删除派工等操作。
依赖方向单向：页面 → `@/api/production` → 后端 FastAPI；UI 辅助逻辑下沉到 `@/utils/display`（`processRowLabel`/`skuRowLabel`/`equipmentOptionLabel`）、`@/utils/status-maps`（`useStatus`）、`@/utils/print`（`openPrintWindow`）、`@/utils/qr`（SVG→PNG/SVG 下载）。权限由 `useAuthStore().hasAnyPermission(['dispatch.manage'])` 控制派工相关按钮可见性。
