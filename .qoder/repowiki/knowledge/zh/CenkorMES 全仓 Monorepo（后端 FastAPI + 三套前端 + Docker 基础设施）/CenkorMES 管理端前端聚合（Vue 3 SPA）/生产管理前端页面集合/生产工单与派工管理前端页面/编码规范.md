- 页面统一以 `AdminPage` 为根容器，在 `#actions` 插槽中放置筛选控件，并通过 `onMounted(() => reload(true))` 触发首次加载。
- 分页采用 offset/limit 模式：`query.offset` 与 `query.limit` 组合，`page = Math.floor(query.offset / query.limit) + 1`，`fakeTotal` 根据当前页数据长度估算总数。
- 所有对外部数据的异步访问包裹在 `loading.value = true` / `finally { loading.value = false }` 中，配合模板里的 `v-loading="loading"` 显示加载态。
- 状态枚举的中文标签与 Tag 类型通过本地函数或 `useStatus('work_order'|'assignment')` 映射，避免在模板中硬编码字符串。
- 需要二次确认的操作统一使用 `ElMessageBox.confirm(...).then(()=>true).catch(()=>false)` 模式，再决定是否调用 API。
- 打印功能统一通过 `openPrintWindow(html, { title, autoPrint: true })` 打开新窗口打印，PDF 导出则先调 `exportTaskLabelPdf` 获取 attachment_id，再用 `http.request({ responseType: 'blob' })` 下载文件。
