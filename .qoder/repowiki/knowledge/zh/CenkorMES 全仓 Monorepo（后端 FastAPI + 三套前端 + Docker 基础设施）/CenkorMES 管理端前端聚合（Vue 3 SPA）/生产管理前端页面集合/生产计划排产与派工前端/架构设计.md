模块以两个路由级页面为入口：`PlansPage.vue` 负责计划列表 + 甘特图 + 各类弹窗/抽屉（齐套检查、工作日历、车间/人员/设备日产能覆盖、自动派工结果、AI 排产对话框），`PlanFormPage.vue` 负责新建/编辑计划及 APS 策略分析。

- `plans/` 子目录按视图职责拆分可复用子组件：`PlanListTable.vue`（表格+分页）、`PlanGanttView.vue`（PC 横向甘特条 + 移动端负荷卡片）、`PlanCalendarDialog.vue`、`PlanAutoDispatchDialog.vue`、`PlanAiScheduleDialog.vue`、`PlanKitCheckDrawer.vue`、`PlanLoadDetailDrawer.vue`，均由父页面通过 props/emits 组合编排，子组件不直接调用 API，仅暴露事件。
- 业务状态集中在父页面：查询参数 `query`、分页 `page/pageSize/fakeTotal`、甘特视图 `ganttDays/loadMap/capacityUnit/loadCapacity`、各弹窗 state（`kit/calendar/workshopCapacity/userCapacity/equipmentCapacity/autoDispatch/aiDlg`）。
- 数据访问统一走 `@/api/plans`、`@/api/ai`、`@/api/automation`，后端模型对应生产计划（production_plan）；自动化开关由 `AutomationSettings` 控制保存后是否触发自动排产/下发/派工。
- 依赖方向：子组件 → 父页面（emit）→ API 层；跨模块复用 `PlanReadinessDrawer`（投产就绪检查）和 `useStatus('plan')` 状态映射。
