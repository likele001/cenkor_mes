三个并列的 Vue 3 `<script setup>` 单文件组件，均作为 `AdminPage` 的子页面挂载在 production 路由下：
- `ReportsPage.vue`：旧版按数量填报的报工记录列表，提供班组长初审、质检终审、驳回（带原因）操作，并通过 `focus_id` query 参数支持从其他页面深链直达详情弹窗；状态标签统一走 `useStatus('report')`。
- `SalaryPage.vue`：计件工资主入口，通过 `el-tabs` 切换「工资明细 / 工资统计 / 补贴扣款」三栏，分别调用 `productionApi.listSalaryLedger`、`getSalarySummary`、`listSalaryAllowances`，并支持按月份+员工+状态筛选、分页、导出 Excel 及手工添加补贴/扣款。
- `SalarySlipsPage.vue`：员工工资条确认页，展示计件/补贴/扣款/实发汇总，支持预览与下载手写签名附件、重置确认状态、批量催签通知。

依赖方向单一向下：页面 → `@/api/production` 中的 `productionApi`（由后端 FastAPI router/crud/services 驱动），附件直接通过 `@/utils/http` 请求 `/files/{id}` 获取 Blob。所有业务数据模型类型（`SalaryLedgerOut`、`SalarySlipOut`、`ReportOut`）由 API 层 TypeScript 类型声明提供，页面不维护本地模型。
