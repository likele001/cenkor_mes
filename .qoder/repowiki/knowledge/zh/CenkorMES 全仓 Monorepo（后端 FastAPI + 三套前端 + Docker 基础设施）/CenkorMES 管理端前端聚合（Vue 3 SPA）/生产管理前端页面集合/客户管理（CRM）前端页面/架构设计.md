模块由两个路由级页面与五个子组件构成：
- `CustomersPage.vue`：客户列表页，封装搜索（keyword / owner_user_id / include_inactive）、分页、创建/编辑对话框、用户负责人下拉与 Excel 导出。
- `CustomerDetailPage.vue`：客户详情页，通过 `<el-tabs>` 组织「可下单产品」「联系人」「销售机会」三个子域；使用 `CustomerActivityDrawer.vue`、`CustomerContactDialog.vue`、`CustomerConvertOrderDialog.vue`、`CustomerLoginDialog.vue`、`CustomerOpportunityDialog.vue` 作为弹窗/抽屉子组件承载对应表单。
- 数据访问统一走 `@/api/production` 暴露的 `productionApi`（listCustomers/getCustomer/createCustomer/updateCustomer/listCustomerContacts/createCustomerContact/updateCustomerContact/deleteCustomerContact/listOpportunities/createOpportunity/updateOpportunity/deleteOpportunity/convertOpportunityToOrder 等），并复用 `masterApi.listProducts` 获取产品选项。
- 权限控制通过 `useAuthStore().hasAnyPermission('customer.manage')` 与 `auth.me.is_superuser` 决定能否筛选负责人、释放公海机会、修改负责人等。
- 依赖方向单向：页面 → 子组件 → productionApi/masterApi → 后端 FastAPI 服务；不直接操作 store，状态以 Vue ref/reactive 在组件内维护。
