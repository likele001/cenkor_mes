- 所有对外部操作的 loading 状态以 provider 字符串为键保存在独立的 ref（saving/testing/acting/clearing/migrating），按钮绑定对应 ref 显示加载态。
- 用户确认类危险操作（激活、清空凭据、启动迁移）统一通过 ElMessageBox.confirm 弹出二次确认，取消时直接 return 中止后续逻辑。
- provider 相关 UI 文案与提示一律通过 t(`system.cloudStorage.*`) 取国际化 key，避免在模板中硬编码中文。
- 对后端返回的配置快照统一经 applyView 合并到 reactive view 对象，再同步到 forms，保证表单与服务器状态一致。
- 长耗时任务采用「启动 + setInterval 轮询」模式，并在 onBeforeUnmount 中清理定时器，避免组件卸载后继续请求。
