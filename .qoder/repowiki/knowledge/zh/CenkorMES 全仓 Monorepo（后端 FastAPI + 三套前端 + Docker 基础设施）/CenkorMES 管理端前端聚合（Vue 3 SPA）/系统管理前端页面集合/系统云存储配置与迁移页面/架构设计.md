单文件 Vue 3 `<script setup>` 组件，作为 system 模块下的路由页面，依赖 `@/components/admin/AdminPage` 提供统一布局与 i18n 标题栏。

- 数据层：通过 `@/api/system` 暴露的 `systemApi` 调用后端 REST（`getCloudStorage` / `saveCloudCredentials` / `testCloudProvider` / `activateCloudProvider` / `clearCloudCredentials` / `updateCloudSettings` / `startCloudMigration` / `getLatestCloudMigration`），并导入 `CloudCredsPayload`、`CloudHealthResult`、`CloudMigrationJob`、`CloudStorageConfigView` 等类型定义，前端不直接访问数据库。
- 视图层：使用 Element Plus 的 Tabs + Form 动态渲染各 provider 字段；`FIELD_MAP` 集中声明 aliyun/tencent/qiniu/upyun 的字段元信息（key、secret、required、hint），由 `providerFields` 派生表单。
- 状态层：`view` 为响应式配置快照，`forms` 按 provider 维护独立凭据表单，`lastTest` 缓存最近一次连通性测试结果；所有写操作经 `applyView` 回写 view 以保持一致。
- 异步迁移子流程：启动后通过 `setInterval` 每 2.5s 轮询 `getLatestCloudMigration`，根据 `status`（pending/running/done/failed）计算进度百分比与标签样式，组件卸载时清理定时器。
- 依赖方向：本页面仅消费 `@/api/system` 生成的客户端 API，不引入业务服务或直连后端，UI 文案全部走 vue-i18n 的 `system.cloudStorage.*` 命名空间。
