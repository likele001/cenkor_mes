本模块为 Vue 3 `<script setup>` 单文件组件集合，每个 `.vue` 文件对应一个独立的管理子页（Users/Roles/Departments/Permissions/CronJobs/Settings/OperationLogs/CloudStorage/FeishuNotify 等），统一通过 `@/components/admin/AdminPage.vue` 作为布局壳，部分列表页复用 `AdminDataTable.vue`。
- 数据层：所有页面通过 `@/api/system` 暴露的 `systemApi`（以及 `@/api/cron-jobs`、`@/api/feishu-notify` 等）调用后端 FastAPI 接口，类型由 `type XxxOut` 导入，不直接操作 HTTP。
- 状态与交互：使用 Vue 3 `ref/reactive/computed` 管理 loading、分页 offset/limit、弹窗表单；表单校验通过 element-plus 的 `FormRules` + `formRef.validate()`。
- 国际化：文案统一走 `vue-i18n` 的 `t('system.xxx')` 或 `$t('<resource>.xxx')`。
- 依赖方向：页面 → `@/api/*` → 后端 FastAPI router/crud/services；页面之间无相互 import，仅共享 `@/components/admin/*` 与 `@/utils/code` 等通用工具。
- 特殊页面：`SettingsPage.vue` 聚合公司资料、报表模式、微信小商店、媒体限制、AI 网关、Prompt、通用 setting key-value 表等多个卡片式配置区块；`CronJobsPage.vue` 单独对接 `cronJobsApi` 管理 Celery 调度器；`UsersPage`/`RolesPage` 在加载时并行拉取关联选项（部门、角色、权限）。
