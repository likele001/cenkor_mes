三个独立的 Vue 3 `<script setup>` 单文件组件，均基于 Element Plus + vue-i18n 构建，统一通过 `AdminPage` 布局容器承载。
- `EquipmentPage.vue`：设备主列表 + 抽屉式「保养管理」子视图，内嵌保养计划（日/周/月检）与保养记录的增删改查；通过 `@/api/equipment` 调用后端设备与保养 API，并复用 `systemApi.listUsers` 加载负责人下拉。
- `ReportUnitsPage.vue`：件次报工审核工作台，支持按状态（submitted / leader_approved / step_*_approved / qc_approved / rejected / draft）与预筛等级（green/yellow/red）筛选；详情弹窗中根据当前审批步骤动态加载质检检查表模板、缺陷代码，并通过 `CameraPhotoCapture` / `CameraVideoCapture` 采集终审证据，最终经 `productionApi.approveReportUnit` 提交附件 ID 与 inspection_results。
- `ShiftsPage.vue`：使用 `el-tabs` 切换「班次管理」与「排班管理」两个子页签，支持单条创建、批量排班（日期范围 × 多员工），导出走 `/admin/shift/export` 直连 HTTP。
依赖方向单向指向 `@/api/*`（equipment / production / shift / system / ai），不反向引用业务模块；UI 样式仅用 Tailwind 原子类，无独立 CSS 文件。
