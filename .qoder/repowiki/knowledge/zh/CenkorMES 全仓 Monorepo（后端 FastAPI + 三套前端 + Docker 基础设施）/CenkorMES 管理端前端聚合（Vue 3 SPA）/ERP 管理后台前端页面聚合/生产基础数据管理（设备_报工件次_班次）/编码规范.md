- 表单弹窗采用 `reactive({ open, saving, isEdit, editId, form })` 集中管理状态，配合 `FormInstance` ref 与 `FormRules` 对象进行校验，保存前统一 `validate().catch(() => false)` 拦截。
- 新增场景通过 `previewNextCode('xxx')` 预取编码并在编辑时禁用 code 字段，提交时用 `codeForSubmit` 规范化后再传给后端。
- 枚举值（status、plan_type、check_result、shift_type、prescreen_level 等）在前端以本地映射函数或常量字典做 label/type 转换，避免硬编码中文散落。
- 异步操作统一包裹 try/finally 释放 loading/saving 标志，成功后 `ElMessage.success` 提示并重新拉取列表数据。
- Excel 导出采用 Blob 下载模式：先置 `exporting=true`，请求成功后构造临时 `<a>` 触发 download，最后 `URL.revokeObjectURL` 清理。
