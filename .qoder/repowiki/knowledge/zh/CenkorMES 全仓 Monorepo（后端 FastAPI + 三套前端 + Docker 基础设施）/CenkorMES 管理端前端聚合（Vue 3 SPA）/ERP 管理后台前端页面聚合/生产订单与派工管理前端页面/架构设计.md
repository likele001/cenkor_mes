三个并列的 Vue 3 `<script setup>` 页面组件，分别对应后端生产模块的三个业务实体：
- `OrdersPage.vue`：订单 CRUD + 审核（draft/pending_confirm/confirmed/producing），含多行 SKU 明细编辑、计划锁定（order_plan_locked）保护、导出 Excel。
- `WorkOrdersPage.vue`：按订单聚合的生产工单列表与详情弹窗，展示工序任务链并支持成品追溯码批量/范围打印。
- `TasksPage.vue`：任务级派工界面，按技能筛选员工、分配数量与设备，支持取消派工、单条/批量打印任务标签及 PDF 导出。

依赖方向单向指向 `@/api/production`（productionApi）、`@/utils/display`（skuRowLabel/processRowLabel/equipmentOptionLabel）、`@/utils/status-maps`（useStatus('order'|'work_order')）和 `@/components/admin/AdminPage.vue`、`AdminDataTable.vue`；权限通过 `useAuthStore().hasAnyPermission(['dispatch.manage'])` 控制派工按钮可见性。所有数据交互走 productionApi，不直接调用 HTTP。
