- 每个实体页面采用相同结构：顶部 `AdminPage` + `#actions` 搜索栏 + `el-table` 列表 + `el-dialog` 内嵌 `el-form` 的新增/编辑弹窗。
- 新增时通过 `previewNextCode('xxx')` 预取下一个编码，提交时再用 `codeForSubmit(dlg.form.code)` 生成最终编码，保持前后端编码规则一致。
- 禁用操作统一使用 `el-popconfirm` 包裹危险按钮，调用 `disableXxx(id)` 后再 `reload(false)` 刷新列表。
- Excel 导出统一通过 `exporting` ref 防抖 + `URL.createObjectURL` 触发下载 + `URL.revokeObjectURL` 清理，失败分支静默吞掉异常（由 HTTP 拦截器提示）。
- 分页查询参数统一包含 `keyword`、`offset`、`limit`、`include_inactive` 四个字段，并通过 `fakeTotal = offset + items.length + (items.length === limit ? limit : 0)` 估算总条数。
- 所有文案通过 `t('master.xxx.key')` 进行 i18n 化，键名按 `master.<entity>.<field>` 命名空间组织。
