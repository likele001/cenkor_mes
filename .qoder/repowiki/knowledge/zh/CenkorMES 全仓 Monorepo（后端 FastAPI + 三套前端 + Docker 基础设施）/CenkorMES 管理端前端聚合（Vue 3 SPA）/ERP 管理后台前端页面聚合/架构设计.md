本模块是 ERP 管理后台的前端入口层，所有页面位于 src/pages/ 下并按业务域（master、production、purchase、warehouse、finance、system、reports、dashboard、account）组织目录；每个子目录对应后端 app/api 下的路由与 app/crud、app/services 实现，并通过共享的 Element Plus + Axios 调用后端 REST API。
- 跨子模块的统一契约：页面通过统一的 API 客户端发起请求，后端以 FastAPI 暴露接口，数据模型由 SQLAlchemy 定义并持久化到 MySQL，部分耗时任务（如排产、薪资核算、报表生成）走 Celery 异步队列。
- 页面之间不直接互相引用，而是通过后端 API 与状态（如登录态、权限码）进行松耦合协作；系统级页面（system/）提供 RBAC、租户、字典等全局能力，被其他业务页面复用。
- 顶层 HomePage.vue 与 LoginPage.vue 作为应用入口与认证入口，其余页面按路由注册进入导航树。
