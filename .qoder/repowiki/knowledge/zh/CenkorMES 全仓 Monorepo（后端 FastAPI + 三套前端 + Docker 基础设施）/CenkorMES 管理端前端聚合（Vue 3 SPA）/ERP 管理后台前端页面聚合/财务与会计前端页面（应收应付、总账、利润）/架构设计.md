本模块为纯 Vue 3 `<script setup>` 单文件组件集合，每个 `.vue` 文件对应一个路由页面：
- 列表型页面：`CustomerStatementsPage.vue`、`SupplierStatementsPage.vue`、`LedgersPage.vue`、`PayablesPage.vue`、`ProfitPage.vue`，统一通过 `AdminPage` 布局 + Element Plus `el-table` + `el-pagination` 实现分页查询。
- 详情型页面：`CustomerStatementDetailPage.vue`、`SupplierStatementDetailPage.vue`，基于 `useRoute().params.id` 加载明细，并提供确认、标记已付、打印、导出 PDF 等操作。
- 数据层完全委托给 `@/api/finance` 暴露的 `financeApi`（以及跨模块的 `productionApi`、`materialsApi`），页面自身不直接发起 HTTP 请求；状态展示复用 `@/utils/status-maps` 的 `useStatus('customer_statement')` / `useStatus('supplier_statement')` 获取标签与颜色。
- 依赖方向单向：页面 → `@/api/*` → 后端 FastAPI 接口；UI 样式由 Element Plus 与 Tailwind 类名构成，业务逻辑集中在 `<script setup>` 中。
