- 所有页面使用 `AdminPage` 作为外层容器并通过 `t('finance.xxx.*')` 进行 i18n 文案国际化。
- 金额统一通过本地 `formatMoney(v)` 函数格式化，空值返回 `-` 或 `0.00`，保留两位小数。
- 列表页采用 `offset/limit` 客户端分页模式，用 `fakeTotal = offset + items.length + (items.length === limit ? limit : 0)` 模拟总数，配合 `page = Math.floor(offset / limit) + 1` 驱动 `el-pagination`。
- 异步数据加载遵循 `loading.value = true; try { ... } finally { loading.value = false }` 的 try/finally 结构，避免异常时卡住加载态。
- 状态标签统一通过 `useStatus('customer_statement' | 'supplier_statement')` 获取 `label` 与 `type`，再绑定到 `el-tag`。
- 需要关联实体名称的页面（如总账、对账单）在 `onMounted` 中预拉取 `productionApi.listCustomers` 与 `materialsApi.listSuppliers`，并缓存为 `Map` 供 `partyOptionLabel` 渲染。
