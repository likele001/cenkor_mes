模块以 `PlansPage.vue` 作为路由入口，承载计划列表、甘特图、工作日历、车间/人员/设备日产能配置、自动派工结果、AI 排产对话框等全部视图；`PlanFormPage.vue` 负责单个计划的创建/编辑表单及 APS 策略分析。`plans/` 子目录下的组件均为纯展示型子组件：`PlanListTable`（列表）、`PlanGanttView`（甘特条拖拽）、`PlanAiScheduleDialog`（LLM + OR-Tools 双标签对话框）、`PlanAutoDispatchDialog`（自动派工结果）、`PlanCalendarDialog`（生产日历）、`PlanKitCheckDrawer`（齐套检查）、`PlanLoadDetailDrawer`（日负荷明细）。状态与业务调用集中在两个父页面中，子组件通过 props / emit 单向通信，不直接访问 API。后端交互统一通过 `@/api/plans`、`@/api/ai`、`@/api/automation`、`@/api/system` 四个 API 模块完成，涉及 Plan、Order、WorkshopCapacity、UserCapacity、EquipmentCapacity、ProductionCalendar、PurchaseOrder 等实体。
