- 所有弹窗/抽屉使用 `destroy-on-close` 销毁 DOM，避免重复渲染导致的副作用。
- PC 端使用 `el-table` 表格，移动端通过 `lg:hidden` / `hidden lg:block` 切换为 `admin-mobile-row` + `admin-mobile-kv` 卡片布局，同一数据在两套模板中并列呈现。
- 子组件仅接收 props 并通过 `defineEmits` 向上抛出事件，父页面集中处理 API 调用与状态更新，子组件不直接 import `@/api/*`。
- 状态枚举（如 plan status、risk level）通过 `useStatus('plan')` 或本地映射函数统一转换为 label 与 tag type，不在模板内硬编码颜色。
- 异步操作使用 `ref(false)` 布尔标志位（如 `saving`、`loading`、`releasingId`）绑定按钮 loading 状态，并在 try/finally 中复位。
