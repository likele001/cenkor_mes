- 列表页统一以 `query = reactive({ keyword, supplier_id, status, offset, limit })` 维护分页查询参数，并通过 `computed(() => Math.floor(query.offset / query.limit) + 1)` 派生页码与 `fakeTotal`。
- 状态标签统一通过 `useStatus('purchase_order')` 获取 `label` 与 `type`，在表格中用 `el-tag` 渲染。
- 异步请求包裹在 `try/finally` 中切换 `loading`/`submitting`/`saving` 等布尔标志，成功或失败后统一通过 `ElMessage.success/warning/error` 反馈。
- 弹窗/抽屉内嵌表格的移动端适配采用 `hidden lg:block` 桌面表格 + `admin-mobile-row` + `admin-mobile-kv` dl/dt/dd 双视图模式。
- 供应商/SKU/工序等下拉选项在 `onMounted` 中通过 `listSuppliers/listSkus/listProcesses` 预加载到本地 ref，供表单选择。
