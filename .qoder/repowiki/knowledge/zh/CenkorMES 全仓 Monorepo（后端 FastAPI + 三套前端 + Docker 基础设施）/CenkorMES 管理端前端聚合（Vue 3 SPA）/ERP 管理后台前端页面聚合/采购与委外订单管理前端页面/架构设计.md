模块由三个独立的 Vue 单文件组件构成，按业务对象拆分：
- `PurchaseOrdersPage.vue`：采购订单列表页，通过 `@/api/purchase.purchaseApi.listOrders` 分页查询，结合 `@/api/materials.materialsApi.listSuppliers` 提供供应商筛选，支持 Excel 导出。
- `PurchaseOrderDetailPage.vue`：采购订单详情页，承载确认/取消、批量收货（含批次号）、退货、打印 PDF 等状态机操作，依赖 `purchaseApi.confirmOrder/cancelOrder/receiveOrder/returnOrder/printOrder/exportOrderPdf` 及仓库下拉数据。
- `SubcontractOrdersPage.vue`：委外工序订单管理，独立实现草稿→已发料→部分收货→已收货→已结算的状态流转，包含新建弹窗（SKU+工序明细表）、发料/收货子弹窗，调用 `subcontractApi.createOrder/updateStatus/sendLog/receiveLog`。

所有页面统一使用项目级 `AdminPage` 布局容器、Element Plus 表格/表单/对话框、`vue-i18n` 国际化、`useStatus('purchase_order')` 状态映射工具；后端 API 均通过 `@/api/*` 生成的 TypeScript SDK 访问，不直接拼接 URL。
