三个独立的 Vue 3 `<script setup>` 单文件组件，均通过 `AdminPage` 作为统一布局外壳，并依赖 `@/api/production` 暴露的 `productionApi` 调用后端 FastAPI 接口：
- `ReportsPage.vue`：旧版按数量填报的报工记录列表，提供初审（leaderApprove）、终审（qcApprove）、驳回（rejectReport）及详情弹窗，状态映射复用 `@/utils/status-maps` 的 `useStatus('report')`。
- `SalaryPage.vue`：以 `el-tabs` 切换「工资明细 / 工资统计 / 补贴扣款」三栏，分别调用 `listSalaryLedger`、`getSalarySummary`、`listSalaryAllowances`，并提供 `exportSalaryExcel` 导出与手动添加补贴/扣款。
- `SalarySlipsPage.vue`：展示已生成的工资条，支持按月份/员工/签名状态筛选、重置确认状态、预览或下载电子签名附件（直连 `/files/{id}`），并提供批量催签（`remindSalarySlips`）。

依赖方向单一：页面 → `@/api/production`（HTTP API 客户端）→ 后端；不直接操作数据库模型，也不引入业务逻辑到组件内。所有金额格式化、时间格式化、状态标签等 UI 辅助函数就地定义在组件内。
