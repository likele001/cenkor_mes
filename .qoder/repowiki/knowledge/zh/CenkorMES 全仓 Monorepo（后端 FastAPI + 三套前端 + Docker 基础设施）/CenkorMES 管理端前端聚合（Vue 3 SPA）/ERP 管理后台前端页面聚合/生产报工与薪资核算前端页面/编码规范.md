- 页面统一使用 `AdminPage` 作为外层容器并通过 `t('production.xxx.*')` 进行 i18n 文案渲染。
- 查询参数集中在一个 `reactive` 对象中（含 `offset`/`limit`/`month`/`user_id`/`status` 等），搜索时重置 `offset=0` 后重新加载。
- 分页采用 offset-based 模式，由 `query.offset = (page - 1) * query.limit` 计算偏移量传给后端。
- 导出 Excel 统一通过 `productionApi.export*` 返回 Blob，再用 `URL.createObjectURL` + 临时 `<a>` 触发下载并在 finally 中释放 URL。
- 异步请求包裹 try/finally 确保 loading 标志复位，错误由全局拦截器处理，catch 块通常留空注释说明。
- 金额显示统一通过本地 `formatMoney` 或 `toFixed(2)` 格式化，并以 `¥` 前缀呈现。
