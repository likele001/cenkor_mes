本模块由 6 个独立的 Vue 3 `<script setup>` 单文件组件组成，每个文件对应一个后台路由页面：
- `WarehousesPage.vue` / `StocksPage.vue` / `WarehouseEntriesPage.vue` / `ShipmentsPage.vue` / `MaterialIssuesPage.vue` / `MaterialReturnsPage.vue`
- 所有页面统一以 `@/components/admin/AdminPage.vue` 作为外层布局容器。
- 数据访问分两条路径：部分页面（如 WarehousesPage、ShipmentsPage）直接通过 `@/utils/http` 调用 `/admin/warehouse/*` REST 接口；另一些页面（如 StocksPage、WarehouseEntriesPage）则通过 `@/api/warehouse` 暴露的 `warehouseApi` 客户端封装调用，类型定义（`StockOut`、`WarehouseEntryOut`、`EntryItemIn`、`WarehouseOut` 等）也来自该 API 层。
- 列表页普遍采用「桌面端 `el-table` + 移动端 `admin-mobile-row` 卡片」的双视图模式，并通过 `computed` 做本地关键词过滤。
- 后端依赖 FastAPI 的 `/admin/warehouse/*` 路由及其对应的 CRUD、Service 实现，数据库模型为仓库、SKU 库存、入库/出库单、发货单等实体。
