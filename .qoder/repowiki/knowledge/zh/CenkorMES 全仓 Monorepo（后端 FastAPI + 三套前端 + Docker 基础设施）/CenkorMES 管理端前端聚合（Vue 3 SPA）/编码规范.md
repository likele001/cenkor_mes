- 新增页面需在 `src/router/index.ts` 中注册路由，并在 `meta.permissions` 中声明所需权限码，由全局路由守卫统一校验。
- 页面组件统一放在 `src/pages/<domain>/` 目录下，命名以 `XxxPage.vue` 结尾，与后端 FastAPI 模块路径保持语义对应。
- 后端 API 调用集中在 `src/api/<module>.ts`，页面侧仅 import 函数而不直接拼接 URL。
- 列表型页面复用 `src/components/admin/AdminPage.vue` + `AdminDataTable.vue` + `AdminFilterBar.vue` 组合，配合 `src/composables/useListPage.ts` 实现统一的增删改查与分页。
- 国际化文案通过 `vue-i18n` 的 `menu.*` 键在路由 meta.title 与页面模板中引用，新增菜单需同步在 locales 文件中添加。
