- 每个实体模块定义本地 `_out(x)` 函数将 ORM 对象序列化为扁平 dict，列表接口用 `[ _out(x) for x in items ]` 批量转换。
- CRUD 操作统一使用 `app.core.response.ok()` 包裹返回值，异常通过 `HTTPException(status_code, detail=...)` 抛出。
- 新增记录前通过 `services.code_generator.resolve_code(biz_type=BizType.XXX, exists=..., duplicate_msg=...)` 生成或校验业务编码，避免重复。
- 删除采用软删除模式：调用对应 update_* 并将 `is_active=False`，而非物理删除。
- 所有路由参数均带类型注解与默认值，分页使用 `offset`/`limit` 配合 `Query(default=50, ge=1, le=200)` 约束。
- 导出功能统一挂在 `/{entity}/export`，通过 `make_excel_response(headers, rows, filename, title)` 返回 Excel 响应。
