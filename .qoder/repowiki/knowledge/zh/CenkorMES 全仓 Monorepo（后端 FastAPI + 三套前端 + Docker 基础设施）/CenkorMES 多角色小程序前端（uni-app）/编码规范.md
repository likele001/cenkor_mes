- API 按角色拆分为 `src/api/admin/` 与 `src/api/h5/` 两个命名空间，所有页面通过对应命名空间下的方法调用后端，而非直接使用 request 实例。
- 页面路由按角色分目录组织：管理端在 `pages-admin/`、员工端在 `pages-employee/`、客户端在 `pages-customer/`，并在 `pages.json` 中注册。
- 可复用的页面逻辑抽取为 `composables/use*.ts`（如 useAdminCrudPage、usePermission、useUpload），供多个页面组合使用。
- 多语言文案集中放在 `src/locales/*.ts`，通过 vue-i18n 注入应用，页面内以 i18n key 引用。
- 权限与菜单通过 `src/constants/permissions.ts` 与 `adminMenu.ts` 集中声明，页面与侧边栏共用同一份配置。
