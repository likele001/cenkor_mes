- 页面统一采用 `<view class="emp-page">` 根容器 + `emp-card` 卡片布局，配合 `emp-btn-primary` / `emp-btn-outline` 按钮类名构建员工端视觉风格。
- 状态展示通过 `status.tone` / `status.text` 结构（由 `taskStatusLabel` / `reportStatusLabel` 生成）驱动标签颜色与文案，避免在模板中硬编码状态映射。
- 异步操作包裹 try/catch 并在 catch 分支用 `uni.showToast({ icon: 'none' })` 提示错误，成功路径用 `uni.vibrateShort` 或 `uni.showToast({ icon: 'success' })` 给予反馈。
- 页面间导航统一使用 `uni.navigateTo` / `uni.redirectTo` / `uni.switchTab`，参数通过 URL query 传递（如 `?task_code=...`、`?month=YYYY-MM`）。
- 可复用数据展示逻辑下沉到 `components/employee-ui/` 下的 Vue 组件，通过 `defineProps` + `computed` 暴露，页面仅负责编排与事件派发。
