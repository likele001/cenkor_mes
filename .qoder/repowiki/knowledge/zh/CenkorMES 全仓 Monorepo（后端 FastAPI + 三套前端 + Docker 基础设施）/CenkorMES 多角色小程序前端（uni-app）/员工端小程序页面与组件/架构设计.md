模块按业务域划分为四个子目录：`report/`（扫码报工 `scan`、手动报工 `manual`、单位报工 `unit`、历史 `history`）、`salary/`（月度汇总 `index`、电子工资条 `slip`）、`notification/`（消息列表 `list`、订阅管理 `subscriptions`）、`task/detail`（派工单详情）。所有页面均为 uni-app 的 `.vue` 单文件组件，通过 `<script setup lang="ts">` 调用 `@/api/h5/*` 后端 API（tasks、salary、notifications、ai），并使用 `@/utils/taskDisplay`、`@/utils/statusLabels`、`@/composables/useUpload` 等共享工具。UI 层在 `components/employee-ui/` 下提供可复用的员工端组件：`EmpTaskCard`（任务卡片+进度条）、`EmpRecordCard`（计件记录卡片）、`BigStepper`（大按钮步进器）、`SignaturePad`（手写签名），被各页面以 Vue props + emits 方式组合使用。依赖方向单向：pages → components/employee-ui → @/api/@/utils/@/stores；页面之间通过 `uni.navigateTo` / `uni.redirectTo` / `uni.switchTab` 跳转，无直接 import 关系。
