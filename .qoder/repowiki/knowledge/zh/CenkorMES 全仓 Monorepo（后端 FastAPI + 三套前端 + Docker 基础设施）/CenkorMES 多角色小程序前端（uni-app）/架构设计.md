以 `src/main.ts` 通过 `createSSRApp` 启动，挂载 Pinia 与 vue-i18n；页面路由由 `pages.json` 按角色拆分到 `pages-admin/`、`pages-employee/`、`pages-customer/` 三个目录，并由 `custom-tab-bar/index.wxml` 与 `mixins/tabBar.ts` 根据当前角色动态渲染底部 Tab。

跨角色共享层集中在 `src/api/`（按 admin/h5 子目录封装后端接口）、`src/stores/`（app/auth 全局状态）、`src/composables/`（useAdminCrudPage、usePermission、useUpload 等组合式函数）、`src/constants/`（adminMenu、permissions、CRUD schema）以及 `src/locales/`（zh-CN/en-US/ko-KR）。各角色页面通过 import 这些共享模块访问后端，不直接调用 wx.request。

UI 组件按角色再分层：`components/admin-ui/` 提供通用 CRUD/Kanban/Ledger 等管理 UI，`components/employee-ui/` 提供报工/签名等员工 UI，`components/customer-ui/` 仅含客户端 TabBar；样式通过 `styles/{admin,customer,employee}-theme.scss` 按角色切换主题。
