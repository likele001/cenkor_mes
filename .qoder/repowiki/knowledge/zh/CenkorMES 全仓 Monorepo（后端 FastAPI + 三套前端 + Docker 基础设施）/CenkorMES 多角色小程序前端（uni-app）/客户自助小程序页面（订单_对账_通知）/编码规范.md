- 页面通过 `onLoad((q) => { id.value = Number(q?.id || 0) })` 从路由参数解析资源 ID，并在 `onShow` 中调用 `requireCustomer()` 做权限守卫后再加载数据。
- 所有用户可见文案走 `useI18n().t('customer.*')` 键值，状态标签通过 `useCustomerLabels` 暴露的 `orderStatusLabel/saleStatusLabel/statementStatusLabel` 等函数转换，避免硬编码中文。
- 列表/详情模板统一采用 `v-if="loading"` → `v-else-if="!items.length"` → 渲染数据的三段式结构，配合 `cust-empty` 占位提示。
- 页面内按钮操作先弹出 `uni.showModal` 二次确认，成功后调用 API 并刷新本地数据，错误由 API 层统一 toast。
- SCSS 通过 `@use '@/styles/customer-theme.scss'` 引入主题，并使用 `cust-page/cust-card/cust-tag/cust-btn-primary/cust-kv-grid` 等公共类名保持视觉一致。
