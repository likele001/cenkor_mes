- 所有网络请求经 `request.ts` 的 `apiGet/apiPost/apiPut/apiDel` 发起，禁止直接调用 uni.request，401 时统一清除 token 并跳转到 `/pages/shared/login/index`。
- 管理端接口统一传入 `admin=true` 参数以附加 `adminHeaders()`，员工端 H5 接口则省略该参数。
- 后端返回的统一结构为 `{ code: number; msg: string; data: T }`，非 200 码由 request 层统一 showToast 并抛出 ApiError，业务代码无需重复错误处理。
- CRUD 页面通过 `useAdminCrudPage(schemaKey)` + `adminCrudSchemas.ts` 中注册的 `CrudSchema` 生成，字段可见性由 `createOnly/editOnly/hiddenOnCreate/miniappExclude` 等 schema 属性控制。
- 权限点集中在 `constants/permissions.ts` 的 `PermissionCode` 对象中声明，并在 `adminMenu.ts` 菜单项中以 `permissions` 数组关联，前后端通过字符串常量保持对齐。
- Pinia store 使用 Composition API 风格的 `defineStore('name', () => { ... })`，状态以 `ref` 声明、方法以普通函数暴露，并通过返回值对象显式导出。
