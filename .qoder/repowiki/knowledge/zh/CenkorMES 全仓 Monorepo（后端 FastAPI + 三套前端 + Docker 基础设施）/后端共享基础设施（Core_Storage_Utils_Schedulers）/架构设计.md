模块按职责拆分为四个子包，彼此单向依赖：
- `app/core`（应用内核）：`config.py` 通过 pydantic-settings 从 `.env` 加载 Settings；`db.py` 暴露 SQLAlchemy engine 与 SessionLocal；`security.py` 封装 bcrypt 密码哈希与 PyJWT HS256 签发/校验；`deps.py` 定义 FastAPI 依赖注入链 `get_db → get_current_user → get_current_permissions → require_permissions/require_any_permissions`，并将权限码缓存到 `request.state.permission_codes`；`redis_client.py` 以全局单例 + 失败降级返回 None；`portal_access.py` 区分 H5 与管理后台角色；`seed.py` 集中维护默认权限点与角色预设；`edition.py` 标记社区版。
- `app/storage`（对象存储层）：`base.Storage` 是 Protocol 接口（save/delete/signed_url/resolve_path），`local.LocalStorage` 实现本地磁盘驱动，`factory` 提供 `_REGISTRY` 驱动注册表与 `build_storage/get_active_storage` 工厂入口（当前仅注册 local，未实现/构造失败时降级为 local 并告警），`_stream.py` 提供限流读取与 sha256 计算工具，`config.py` 预留 CloudDriverConfig 数据结构。
- `app/utils/upload_mime.py`：上传 MIME 白名单与扩展名纠偏，含 HTML/SVG/XSS 头部检测 `looks_like_web_content`。
- `app/schedulers/database.py`：继承 `celery.beat.Scheduler` 的 `DatabaseScheduler`，从 `cron_jobs` 表加载 crontab 并通过 Redis key `celery:beat:reload` 每 10 秒检查热重载。
依赖方向：业务模块 → core/deps → security/db/config；storage 与 utils 被上层 API/crud 调用；schedulers 独立于 Web 请求链路。
