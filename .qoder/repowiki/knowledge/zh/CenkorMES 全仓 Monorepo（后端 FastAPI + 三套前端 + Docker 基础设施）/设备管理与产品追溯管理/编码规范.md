- 路由级权限控制通过 `APIRouter(dependencies=[Depends(require_permissions([...]))])` 声明，而非在每个端点重复装饰。
- CRUD 端点统一使用 `get_db` / `get_current_user` 注入 Session 与 User，并在写入后显式调用 `db.commit()`。
- 返回体一律经 `ok({...})` 包装，字段按需投影为字典，避免直接暴露 ORM 对象。
- 创建接口中的业务编码通过 `resolve_code(db, biz_type=BizType.X, exists=..., duplicate_msg=...)` 生成并校验唯一性。
