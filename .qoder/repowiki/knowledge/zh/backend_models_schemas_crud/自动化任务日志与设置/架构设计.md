模块按三层划分：
- 数据模型层 `app/models/automation_log.py` 定义 `AutomationLog` ORM 类，映射 `automation_logs` 表，字段覆盖 trigger/action/status/biz_type/biz_id/message/detail_json/created_by/created_at，并对 trigger、biz_id、status、created_at 建索引以支撑按触发源和状态检索。
- 请求模式层 `app/schemas/automation.py` 暴露两个 Pydantic 入参模型：`AutomationSettingsIn` 用于启用各自动化子域（on_order_confirm/on_plan_saved/audit/briefing/alerts）及其参数；`AutomationDryRunIn` 用于对订单或计划的自动化执行进行干跑验证。
- 数据访问层 `app/crud/automation_log.py` 提供 `create_automation_log`（将 detail dict/list 序列化为 JSON 字符串存入 `detail_json`，message 截断至 512 字符）和 `list_automation_logs`（支持按 trigger/status/biz_type/biz_id 过滤并分页倒序）。依赖方向单向：CRUD → Model，Schema 独立于两者供 API 层复用。
