- ORM 模型统一继承 Base，使用 Mapped/MappedColumn 类型注解，并在 __table_args__ 中以 UniqueConstraint 声明业务唯一键。
- 时间戳字段采用 created_at/updated_at 双列，created_at/server_default=func.now()，updated_at/onupdate=func.now()。
- CRUD 以纯函数形式暴露（get_/list_/create_/update_），首参为 Session，返回 ORM 实体或 None。
- 对外部可选外键使用 ondelete="SET NULL"，对强关联外键使用 ondelete="RESTRICT"，级联删除用 CASCADE。
- DTO 通过 Pydantic Field 的 min_length/max_length/ge 等参数做入参校验，Create/Update/Out 三类 schema 分别对应写入、增量更新与只读输出。
